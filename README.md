# Cold-Cylinder 无限长圆柱体冷等离子体工作模型

这是用 **C11 + Tcl/Tk** 实现的天线与冷等离子体工作台。它从给定天线电流出发，计算圆柱几何中的电流谱、真空/等离子体全矢量场、吸收、有限模式范围的空间重建，以及局部色散分支和射线路径。两平台共用求解内核：Windows 使用 `Cold-Cylinder.exe`，macOS 使用 `Cold-Cylinder.app`；源码和构建入口位于 [`工程文件`](工程文件)。

本 README 汇总原 `工程文件/docs/` 四份说明及 C11 工作台开发说明，统一维护操作、模型、公式、图表单位、验证和源码开发约定。[源码组织与开发约定](#development)及[代码核验记录](#code-audit)也在本文件中；完整理论推导见 [主 PDF](天线电流谱文档/Finite_width_antenna_current_spectra.pdf) 和 [主 LaTeX（源码包）](天线电流谱文档/Finite_width_antenna_current_spectra.tex)。运行包附本 README、对应平台程序及主 PDF；`工程文件/`、主 LaTeX 和构建脚本的路径/链接仅用于源码目录。整理日期：2026-10-30。

先区分四件事：天线电流是输入；等离子体响应电流是求解结果；单模场是固定 `(m,k_z)` 的谱量；空间总场由复振幅相干叠加得到。程序没有馈电端口、电路反馈或导体电流的自洽重分布。“全模式”始终指用户指定的有限 m、k_z 范围。

## 1. 快速开始：构建、启动和 CLI

### 使用已打包的程序

| 平台与目标架构 | 交付 ZIP | 解压后的启动入口 |
|---|---|---|
| Windows 10/11 x64 | `交付/Cold-Cylinder-Windows-x64.zip` | 双击 `Cold-Cylinder.exe`，或同目录 `Start-Cold-Cylinder-Windows.cmd` |
| macOS arm64（Apple Silicon） | `交付/Cold-Cylinder-macOS-arm64.zip` | 双击 `Cold-Cylinder.app` |

Windows ZIP 要完整解压到一个目录，再运行其中的程序；`tcl86.dll`、`tk86.dll`、`zlib1.dll`、`lib/`、`examples/` 和 `licenses/` 与程序一起保留。GUI 和命令行分别为 `Cold-Cylinder.exe` 与 `Cold-Cylinder-cli.exe`，共用同一内核与资源。macOS 应用自身包含对应运行库和示例，可整体移动。当前没有提供 Intel Mac 或 Windows ARM 的原生产物。

Windows 命令行在解压后的目录执行：

```powershell
.\Cold-Cylinder-cli.exe --check
.\Cold-Cylinder-cli.exe --help
.\Cold-Cylinder-cli.exe --plasma --project ".\examples\等离子体螺旋示例.rfproj" --output ".\plasma.csv"
```

### macOS 源码构建和启动

在项目根目录执行：

```sh
make                 # 构建 C11 工作台
make check           # 加载默认状态并检查参数
make run             # 打开 Tcl/Tk 窗口
```

日常使用可直接双击已打包的 `Cold-Cylinder.app`。Linux 或自定义 Tcl/Tk 安装可在 `工程文件` 中设置 `TCL_CFLAGS` 和 `TCL_LIBS`；缺少 GUI 开发文件时仍可构建 CLI。下列 Makefile/Unix 路径命令用于源码构建，Windows 的原生入口见下一小节。

根目录 Makefile 提供常用 CLI 包装：

```sh
make vacuum ARGS="--project 工程文件/examples/04_loop.rfproj --output /tmp/vacuum.csv"
make plasma ARGS="--project 工程文件/examples/等离子体螺旋示例.rfproj --output /tmp/plasma.csv"
make geometry ARGS="--project 工程文件/examples/05_helix.rfproj --obj /tmp/helix.obj"
```

直接调用工作台时，完整选项可用 `./工程文件/.build/rf-workbench --help` 查看：

```sh
./工程文件/.build/rf-workbench --check \
  --project 工程文件/examples/等离子体螺旋示例.rfproj
./工程文件/.build/rf-workbench --vacuum \
  --project 工程文件/examples/04_loop.rfproj --output /tmp/vacuum.csv
./工程文件/.build/rf-workbench --scan \
  --project 工程文件/examples/04_loop.rfproj --kpoints 41 --output /tmp/scan.csv
./工程文件/.build/rf-workbench --plasma \
  --project 工程文件/examples/等离子体螺旋示例.rfproj --output /tmp/plasma.svg
./工程文件/.build/rf-workbench --geometry \
  --project 工程文件/examples/05_helix.rfproj --obj /tmp/helix.obj
```

### Windows 原生构建和打包

在完整源码目录中双击 `Build-Cold-Cylinder-Windows.cmd`，或在终端运行：

```powershell
.\Build-Cold-Cylinder-Windows.cmd
```

该入口调用 `工程文件/build/windows/build.ps1`。脚本优先使用显式指定的工具链、`COLD_CYLINDER_COMPILER_ROOT`、已安装的 llvm-mingw 或 MSYS2 UCRT64；没有合适编译器时下载固定版本 **llvm-mingw 20261020 UCRT x64**，核对 SHA-256 后缓存。Windows Tcl/Tk 8.6.18 与 zlib 依赖来自源码内的 `deps/windows-x64.zip`，同样先校验哈希再展开到 `%LOCALAPPDATA%\Cold-Cylinder`。构建不需要 make、AWK、Python 或管理员权限，首次自动下载编译器需要网络。

已有工具链时可禁止下载；路径包含空格时保留引号：

```powershell
powershell -NoLogo -NoProfile -ExecutionPolicy Bypass -File ".\工程文件\build\windows\build.ps1" -CompilerRoot "C:\llvm-mingw" -NoDownload
```

脚本还接受 `-TclTkRoot`（自备 `bin/include/lib/licenses` 依赖目录）和 `-OutputDirectory`。所选编译器必须是支持 C11 原生复数的 **x64 MinGW-w64 UCRT Clang/GCC**；MSVC/clang-cl 不在当前构建路线中。输出为 `交付/Windows-x64/` 和 `交付/Cold-Cylinder-Windows-x64.zip`，已包含运行依赖、26 个示例、许可、总说明和主 PDF。

构建在独立暂存目录完成，检查 PE 架构和非系统 DLL 依赖后再发布；失败保留旧可用包。已有非空输出目录必须带有效的 Cold-Cylinder 构建标记，脚本不会覆盖任意用户目录。原生 Windows 构建会运行打包后的 CLI `--check`。源码根目录的 `Start-Cold-Cylinder-Windows.cmd` 查找已构建的 Windows 包；它用于启动，不会自动编译。

跨平台构建使用同一 PowerShell 脚本的 `-CrossCompile`，要求显式提供适用于构建主机的 `-CompilerRoot` 和 Windows `-TclTkRoot`，不自动下载 Windows 主机编译器，也不将编译成功当作 Windows 运行验收。

### macOS 运行库与独立应用

`工程文件/deps/macos-arm64.zip` 保存 Tcl/Tk 8.6.18，避免 macOS 26 下系统 Tk 8.5 的空白窗口问题。首次构建按压缩包摘要展开到 `~/Library/Caches/Cold-Cylinder/runtime/`；工程内只生成 `.build/runtime` 链接和 `.build/rf-workbench`。可用绝对路径环境变量 `COLD_CYLINDER_CACHE_DIR` 自定缓存位置。源码中的 Tcl 界面在构建时嵌入 C 可执行文件，运行时不需要读取源码。

```sh
make app             # 更新独立 .app，并生成交付目录内的 macOS arm64 ZIP
make -C 工程文件 runtime  # 从固定版本与校验和重建 macOS 运行库
```

`make app` 从空暂存目录组装应用，执行本地签名检查和打包程序的 `--check`，再更新根目录 `.app`；同时将该应用、总 README 和主 PDF 写入 `交付/Cold-Cylinder-macOS-arm64.zip`。内置运行库和当前产物为 arm64；其他架构需要对应工具链和运行库重新构建并验证。只需要命令行时，可用 `make -C 工程文件 GUI=no` 构建不链接图形库的版本。

### 启动入口的区别

| 入口 | 行为 | 适合场景 |
|---|---|---|
| 双击 `.app` | 运行最近一次打包的程序，自带 Tcl/Tk 和示例 | 日常使用、复制到其他位置 |
| 双击 `Cold-Cylinder.exe` | 运行 Windows GUI，使用同目录 DLL 与 `lib/` | Windows 免安装运行包 |
| `Cold-Cylinder-cli.exe` | 使用显式参数执行命令行计算或导出 | Windows 终端与脚本 |
| `Build-Cold-Cylinder-Windows.cmd` | 检查/准备 Windows 工具链并编译、打包 | Windows 源码构建 |
| `Start-Cold-Cylinder-Windows.cmd` | 启动已解压或已构建的 Windows GUI | Windows 双击启动 |
| `make run` | 先按依赖检查并构建源码，再进入 GUI | 修改代码后查看最新实现 |
| 直接运行 `rf-workbench` | 执行现有源码可执行文件，选项控制 CLI 或 GUI | 脚本、批处理和数据导出 |

更新源码后使用 `make run`，更新独立应用使用 `make app`。`GUI=no` 只构建 CLI，不能用于独立 GUI 应用打包。

本程序需要同时支持 **Windows 和 macOS**。清理目录时须保留共享求解器、Tcl 界面源码、公共头文件及构建资料，按两种平台分别准备启动程序和运行依赖。

## 2. 界面、参数与七个计算栏目

### 布局、参数和操作按钮

窗口采用「左侧参数输入—中间天线建模—右侧运算结果」三栏布局，可以缩放。左侧是「天线」「介质」「扫描」「射线追踪」四个参数页，字段附带单位，较长参数页保留滚动条拖动，触控板和鼠标滚轮不滚动左侧参数。

参数名称、单位、输入值、页签和说明统一使用 20 号字，分组标题使用 18 号粗体。参数名称与数值框紧邻，数值左对齐；右侧固定栏目使用 16 号粗体、图示选项和操作按钮使用 18 号字，图例及坐标文字使用 14 号字。选项较多时可滚动查看，保留图表空间。无关的天线参数自动隐藏，常用项紧凑排列，高级相位、位置及采样参数默认收起。

字体按平台选择可用的中文界面字体，并为数值输入配置协调的数字字体；保持原有字号、参数左对齐和统一输入框对齐，不用缩小字号来适应 Windows。字体回退按系统可用家族选择，避免缺字或不匹配的替代字体。

| 用途 | macOS 优先字体 | Windows 优先字体 | 字号 |
|---|---|---|---:|
| 参数名称与中文选择项 | 苹方 PingFang SC | Microsoft YaHei UI → Microsoft YaHei → DengXian | 20 |
| 数值输入 | Helvetica Neue → Arial | Segoe UI → Arial | 20 |

缺少候选字体时回退到系统默认字体；其余标题、栏目、按钮及图表保留既有字号层级。侧栏按真实字体及两列控件的请求宽度补足最小宽度，保持紧凑间距。此次本机字体检查中 macOS 侧栏维持 360 像素；Wine 的备用字体较宽，侧栏增至 377 像素。两端逐页检查的 95 个输入/选择控件均未越出表单边界，正常参数文本无裁切。

顶部左侧提供打开、保存、更多（另存为和内置示例），右侧为开始计算、停止和 CSV/SVG 导出；所有操作按钮统一为圆角风格并在同一行对齐，窗口标题固定为「Cold-Cylinder 无限长圆柱体冷等离子体工作模型」；打开其他工程或修改参数时保持不变，未保存修改仍通过保存确认处理。

快捷键：Command/Ctrl+O 打开，Command/Ctrl+S 保存，Command/Ctrl+Enter 开始计算。

### 几何预览与无限长显示

中间持续展示天线与圆柱容器的三维模型，随左侧参数更新。天线按电流源积分中的有限带面边界绘制，电流带宽不再用有上限的像素线宽代替；长度、回路宽度、张角及源展宽使用同一物理比例尺。零宽电流显示为细中心线，箭头仅指示电流方向。拖动可旋转、滚轮可缩放，点击「复位」恢复初始三维视角。左下角以 r、φ、z 示意柱坐标，方位角 φ 用绕轴的弧箭头表示；坐标示意与下方操作说明、底部按钮保留间距。输入无效或尚未完整时提示原因，并保留上一份有效模型。容器侧面以浅灰蓝色半透明填充；选中等离子体栏目时，内部区域以蓝色半透明圆柱显示。

中间画布铺满中栏，圆柱只占总高度的 64%，上下各留 18% 空白并标注 +∞、−∞；标题、说明和操作按钮悬浮显示。横向不自动拉满；三维几何共用同一物理比例尺，半径参数直接决定显示宽度。默认视图每个画布高度对应 5 m，可用滚轮统一缩放。两者沿轴向显示到截断边界，保持均匀透明度，不做两端渐隐，也不绘制端盖。视图边缘不代表等离子体长度或轴向边界。两层表面与天线路径按深度混色，保留内部天线的可见性。

### 先选择要计算的量

| 栏目 | 固定量与叠加范围 | 显示形式 | 图数 |
|---|---|---|---:|
| 真空单模场 | 固定 f、m、k_z，材料设为真空 | r 曲线 | 3 |
| 真空波数谱 | 固定 f、m，逐点扫描 k_z | k_z 曲线、k_z–r 热图 | 5 |
| 等离子体单模场 | 固定 f、m、k_z，使用当前材料响应 | r 曲线 | 7 |
| 等离子体波数谱 | 固定 f、m，逐点扫描 k_z | k_z 曲线、k_z–r 热图 | 7 |
| 等离子体总场 | 固定 f，对所设整数 m 求和、k_z 带相干积分 | 固定可调 φ 的 z–r 热图；壳层量全圆周积分 | 7 |
| 电势波形 | 固定 f、当前 m，对 k_z 带相干积分，φ=0 | 沿 r 的 Im Φ 波形、沿 z 堆叠 | 1 |
| 色散与射线 | 固定 f、m、k_z，求局部分支并筛选指定起点 | 径向诊断和三维路径的投影/沿程量 | 8 |

计算栏目依次为：**真空单模场 → 真空波数谱 → 等离子体单模场 → 等离子体波数谱 → 等离子体总场 → 电势波形 → 色散与射线**。“色散与射线”的图例可自动附注 helicon、TG 或离子回旋频段快/慢波型，波型与传播状态独立判定；“更多”提供“离子回旋快慢波识别示例”。“单模场”指固定 `(m,k_z)` 的 Fourier 分量；“总场”指设定范围内各 m、k_z 的相干叠加；“电势波形”保留单 m 的 k_z 带重建，具体图名仍为“电势虚部波形堆叠”。

真空和等离子体栏目同时显示，直接选择栏目即可计算对应模型，无需“启用等离子体”开关：真空模式共 8 种图示，包括场与能流、电流谱及波数扫描，真空天线电流谱只保留幅值图；等离子体模式共 30 种。“等离子体单模场”合并原来的场与电流、空间吸收与沉积栏目，提供电场幅值、磁场幅值、轴向能流密度、电流幅值、局部吸收、径向壳层沉积、波阻抗幅值共七张 r 曲线；吸收和沉积各保留一个入口，七图使用同一次固定 (m,k_z) 求解。局部吸收单位为 W/m，壳层沉积为 W，波阻抗幅值为 Ω。扫描范围和全模式 m 范围不参与单模式求解。“电势波形”栏目现显示一张“电势虚部波形堆叠”：先在外壁 Φ=0 的库仑规范中从全电磁场提取标量电势，再对单 m、扫描 k_z 带相干重建，画 Im Φ（V），沿 r 取波形、沿 z 堆叠；原三个电场分量堆叠已替换。该栏独立保存快照。给定源的“电流谱幅值”归入“真空波数谱”，独立的“天线电流谱”栏目已移除，材料与介电张量剖面不显示；已删除的累计吸收及累计比例谱图不恢复。

场图包括电场幅值、重建磁场幅值和轴向能流密度；电场、磁场及响应电流幅值图均显示矢量总幅值和三个分量，总幅值为各复分量模平方和的平方根。真空扫描提供电场幅值（截面最大值）、电流谱幅值、轴向能流谱、总电场谱热图和磁场谱热图。“等离子体波数谱”后的“等离子体总场”对可调 m 范围求和、对扫描 k_z 范围相干积分，提供与单模式栏目对应的七张 r-z 图，观察方位 φ 可调；电场、磁场和响应电流可切换总幅值及 r/φ/z 分量，轴向能流保留正负号。局部吸收为所选 φ 截面的 q，壳层沉积对完整圆周积分。波阻抗幅值先叠加总复电场和磁场，再计算 μ₀‖E_total‖/‖B_total‖（Ω），磁场节点留空；该局部幅值比不等于端口负载阻抗。求和范围、φ 和空间窗口/网格在“扫描”页设置。“全模式”表示所设有限范围，需检查截断收敛。等离子体扫描另含吸收谱、负载阻抗谱和吸收热图，不再显示 Er、Eφ、Ez 分量谱热图。

切换栏目会保留各自计算结果，模型预览随所选栏目显示真空或等离子体。七个计算栏目位于右侧结果区顶部，完整名称横向固定一排，使用 16 号粗体、清晰的深灰分割线和蓝底白字选中状态。宽度不足时直接隐藏整排栏目，加宽后自动恢复。具体图示继续放在右侧，以浅蓝描边圆角标签显示，使用 18 号字，可随右侧宽度换行；计算后保留预选图示。图形直接读取 C 内核的结果数组；图例支持隐藏分量，移动指针可查看数值。

### 计算快照、进度和导出

波数扫描逐点运行，底部显示进度，可点击「停止」或按 Escape 取消。停止或计算失败时保留上一份完整结果；修改参数后，结果会标记为旧快照。导出 CSV 保存复数分量（热图导出波数、半径和数值），SVG 保存当前曲线或热图，中间建模区支持 OBJ 中心线导出。扫描失败点会在曲线和热图中留空，原因保存在 CSV 的 error 列。热图每个波数最多保留 129 个径向节点，峰值、能流和吸收积分仍使用完整计算网格。

### 密集电势波形的显示

电势波形自动将 z 采样加密至至少 401 点（总网格上限内），最多绘制 501 条真实切片。采用细线，增益不随线数降低；图上“起伏 ×0.5 / ×1 / ×2 / ×4”按钮可直接调整显示，不必重新求解。波形任务保留原模态电势求解，省去未使用的空间吸收高阶积分，专用 CSV 记录真实复电势及求解误差。

### 参数设置的基本顺序

1. 选择天线并设置尺寸、给定电流、频率和选中的 m、k_z；先检查中间模型是否符合预期。
2. 研究等离子体时设置半径、密度剖面、磁场、离子种类和材料响应。有限碰撞使用输入阻尼；零碰撞极限使用内部趋零序列。
3. 单模计算直接运行；波数谱设置 k_z 范围与点数；总场再设置 m 上下限、φ、z 窗口和显示点数；电势波形使用当前单 m。
4. 射线另外设置发射位置、能流方向和步长/误差预算。先看分支状态与 WKB，再解释是否存在可发射轨迹。
5. 比较结果时核对冻结快照，逐项加密径向网格、求积、k_z 和 m 范围；不要把仅改变显示倍率当成重新求解。

## 3. 物理模型、坐标和 Fourier 约定

背景、材料界面和 PEC 圆管只随 r 变化；轴向无界，无端盖。几何显示中的 `length` 是观察窗口，不是求解域的轴向导电边界。天线是给定电流的有限宽度、零厚度带面，包含模板规定的回流和径向连接段。天线电流不由导体内部或端口电路反求。材料为有阻尼的冷电子和单离子流体，B0 沿 z；没有温度输运、Landau 阻尼或有限 Larmor 半径响应。

采用峰值相量 `exp(i m phi+i kz z-i omega t)`，正变换为 `∫dz ∫dphi/(2pi)`，逆变换为 `sum_m ∫dkz/(2pi)`。不同 `(m,kz)` 独立；每个模态内的电场分量保留耦合。

| 对象                             | 谱单位 |
| ------------------------------ | --- |
| 电场 E_hat                       | V   |
| 射频磁场 B_hat                     | T m |
| 规定体源 J_ant_hat、材料响应电流 J_pl_hat | A/m |
| 单源面 K、展示用径向汇总 K_eff            | A   |
| q_spec=Re(J_pl_hat·E_hat*)/2   | W/m |
| dP_abs/dkz=∫r q_spec dr        | W m |

`dP/dkz` 不等于已经对波数和全部模式积分的总功率。单模结果的吸收总量和单点 CSV 使用 W·m；已删除的累计吸收图不再作为独立入口。总功率要在选定模式和波数范围内积分，并检查谱截断与步长收敛。空间重建及带内复阻抗已由 `spatial.c` 提供，见 [无限长空间吸收与阻抗](#spatial-reconstruction)。极限吸收的检查按单个谱片进行，不表示已证明极限可与完整谱积分交换。

### 坐标、电流方向和驱动相位

z 沿圆柱轴，phi=atan2(y,x)；从 +z 看向原点，+phi 为逆时针。几何方向不自动等于装置的环向或极向。每段有端点 a→b、带符号的支路系数 A 和单元相位 phi_e。峰值相量采用 `exp(-i omega t)`：

```text
I_e(t) = sigma I0 A cos(phi0 + phi_e - omega t)
sigma = current_direction = ±1
phi0 = global_phase_deg × pi/180
phi_e = e × phase_step × pi/180    （阵列单元）
```

整体反向等价于整体相位加 180°，不改变几何绕向。`winding_direction` 改变螺旋的 `dphi/dz=chi 2pi turns/L`，chi=±1；它不单独决定波的左右旋极化。阵列的电流相位与单元空间位置分别进入源积分。

### Fourier 正反变换与量纲

令 F 代表任一场分量，采用

$$
\widehat F_m(r,k_z)=\int_{-\infty}^{\infty}dz\int_0^{2\pi}\frac{d\phi}{2\pi}
F(r,\phi,z)e^{-i(m\phi+k_z z)},\qquad
F(r,\phi,z)=\sum_m\int_{-\infty}^{\infty}\frac{dk_z}{2\pi}
\widehat F_m(r,k_z)e^{i(m\phi+k_z z)}.
$$

方位 Fourier 指标 m 为整数、无量纲，轴向波数 k_z 用 rad/m，频率输入 MHz，内核使用 ω=2πf。正变换包含一个 z 积分，所以谱电场的单位为 V，而空间电场为 V/m。相同原因使谱磁场、电势和响应电流各比对应空间量多一个长度量纲；完整对照见[图表单位](#plot-units)。

背景的轴对称和轴向平移不变性使不同 `(m,k_z)` 的线性求场彼此独立，但同一模态内部的 r、φ、z 分量仍然耦合。将模态结果重建为局部吸收或能流时，需要保留复振幅的干涉项。

### 三种计算层次的区别

| 层次 | 求解对象 | 不能直接混同的量 |
|---|---|---|
| 固定 `(m,k_z)` 全波边值问题 | 天线源激发的谱场、谱吸收和等效负载贡献 | 谱值不是已经积分的空间功率 |
| 有限 m/k_z 空间重建 | 全波复场的相干叠加，再构造吸收和能流 | 局部吸收不能由吸收谱直接逆变换 |
| 局部色散与射线 | 无源局部波矩阵的根、极化、群速度和路径 | 单位极化与归一化轨迹功率不是天线激发幅度 |

模型不包含端口自洽电流、导体欧姆损耗、匹配网络、有限端盖、开放径向辐射边界、温度和动理学响应。径向 PEC 壁和轴向无界条件在所有栏目保持一致；射线在壁面终止，并不自动补上反射波。

### 容易混淆的长度与半径

| 符号/参数 | 含义 | 是否构成物理边界 |
|---|---|---|
| R / `radius` | PEC 圆管外壁半径，m | 是，切向电场为零 |
| a / `plasma.radius` | 等离子体半径，m | 是材料界面，外侧为真空 |
| b / `antenna_radius` | 天线参考半径，m；部分模板含多个实际半径 | 是源几何参数，不能替代真实径向源分布 |
| L / `antenna_length` | 天线源的轴向长度，m | 限定规定电流的支撑，不是端板 |
| W / `band_width` | 电流源的跨宽平均范围，m | 是源展宽，不是导体厚度 |
| `length` | 三维模型的显示长度，m | 否，求解仍为轴向无限 |
| `zmin/zmax` | 空间重建的观察窗口端点，m | 否，只截取观察与积分范围 |

## 4. 17 类天线与给定电流源

本说明对应 `工程文件/src/geometry.c` 的参数化模板、源积分和 OBJ 导出。有限带宽推导见 [PDF](天线电流谱文档/Finite_width_antenna_current_spectra.pdf) 及其 [LaTeX 源码](天线电流谱文档/Finite_width_antenna_current_spectra.tex)；场方程、边界与验证见 [Maxwell 求解器实现与验证](#maxwell-solver)。

### 模板与项目编号

当前天线目录为 17 类，PDF、菜单和 `.rfproj` 的 `type` 统一使用 1–17。项目格式为 v8；读取 v7 时自动迁移旧 6、7、8 号，保留物理位型。以下方向均取正电流并忽略整体相位：

| type | 模板 | 规定路径与主要参数 |
|---|---|---|
| 1 | ICRH 单带 | 同一 r=b 圆柱上的矩形回路：低方位腿沿 +z、顶弧沿 +phi、另一腿沿 -z、底弧沿 -phi；使用 width、L |
| 2 | ICRH 多带阵列 | 多个单带回路，中心方位间隔 spacing/b，电流相位递增 phase_step |
| 3 | Helicon 梳状阵列 | 同样采用贴圆柱矩形单元，保留各单元间距与给定驱动相位 |
| 4 | 全匝单环 | r=b，沿 +phi 闭合，带宽沿 z 展开 |
| 5 | 双臂螺旋 | 一臂向上、另一臂向下回流，两端完整环；两个闭合支路各带 I/2，共享主腿相加为 I；使用 turns、winding_direction、L |
| 6 | 单鞍 | 一个圆柱矩形回路，方向与单带相反；使用 arc_angle_deg、L |

| 8 | Nagoya III | 两条相对轴向腿和两端完整环；每条端部半环带 I/2，相当于未扭转的双臂连接 |
| 9 | 线电流含回流 | 局部 x=b 直弦从 -y 到 +y，外半径 c_ret 上的右侧圆弧返回；直弦长度 2 sqrt(c_ret²-b²) |
| 10 | 部分匝环 | b 上圆弧沿 +phi，两条径向连接段接到 c_ret 上的反向回流圆弧；使用 arc_angle_deg |

| 12 | 四半匝／半匝阵列 | 部分匝回路按 2pi e/N 均布；使用 elements、phase_step、arc_angle_deg，空间间距不使用 spacing |

| 15 | 分段多环 | elements 个等间距半径；内环分两段，外环各四段，gap_angle_deg 指定间隙；按段中心采样 cos(q phi) 或 exp(i q phi)，段内电流保持常值 |

### 几何参数与有限带宽

`width` 是单带及矩形阵列两根轴向腿的圆周弧长间距 d，张角 alpha=d/b；鞍形模板改用 `arc_angle_deg`。`band_width` 是独立的物理电流带宽，默认 0.02 m。两者不能互换。矩形带的外边界不能绕满一周，带宽须小于腿间距和轴向长度。

闭合模板的有限带宽通过跨宽闭合等流线的 `du/band_width` 平均实现；开路径及新增模板使用其各自规定的横向平移平均，不人为补上回流。矩形等流线尺寸为 `(d+2u,L+2u)`，保留展开面上的矩形直角；螺旋、圆弧、连接段和回流按各自带面计算。`band_samples` 是宽度求积设置，积分还按相位变化细分；不能用可视中心线代替实际带面源。

场求解与展示源谱共用 `geometry_integrate_source`，但展示的径向汇总 `K_eff` 不包含源半径分布，不能把它集中加载到名义半径。半 Nagoya 的汇总 Kz 可以为零，而内外两腿分别加载后仍产生非零 Ez。

天线电流为给定输入。同一天线参数在真空和等离子体中的规定源谱相同；响应场和等离子体电流由材料与全局方程决定。模型不反求端口电压或受等离子体加载影响的导体电流。



### 单带零带宽谱参考

以下是 type=1 的解析检查，不能代替一般有限带宽积分。正变换为 `integral dz integral dphi/(2pi) exp[-i(m phi+k z)]`，记

```text
alpha = d/b
Pphase = exp(i phi0 - i m theta - i k z0)
Is = sigma I0
sinc(x) = sin(x)/x，sinc(0)=1

Kz   = i Is L/(pi b) sin(m alpha/2) sinc(k L/2) Pphase
Kphi = -i Is alpha/pi sinc(m alpha/2) sin(k L/2) Pphase
Kr   = 0
Jhat(r) = delta(r-b) (Kphi e_phi + Kz e_z)
```

K 的单位为 A，满足 `(m/b)Kphi+k Kz=0`。m=0 或 k=0 可直接取值，无需除以它们；m=k=0 时该矩形回路的汇总谱为零。弱形式源项为

```text
i omega mu0 b [conj(v_phi(b)) Kphi + conj(v_z(b)) Kz]
```

b 来自圆柱测度，Fourier 的 `1/(2pi)` 已包含在 K 中。Jr=0 是源路径的性质，不表示耦合场 Er 必须为零。



### 新增给定电流的输入约定

14、15 号使用 `inner_radius < antenna_radius`；15 号径向环数为 1–8，间隙角为 0–90° 的开区间。`source_mode=q` 定义输入电流分布，`selected_m` 选择输出 Fourier 分量；两者独立。`current_pattern=0` 是 cos(q phi)，=1 是 exp(i q phi)。鸟笼要求 N>=3 且 1<=q<N；端环电流由 T_j-T_(j-1)=G_j 确定，而不是统一赋 I0。蛇形的 width 是每段横向弧长，spacing 是轴向节距；current_phase_gradient 的单位为 rad/m，默认 0。

13–15 号的 band_width 表示轴向均匀源展宽，16、17 号表示角向均匀源展宽（弧长单位 m）；分别产生 sinc(kz W/2) 和 sinc(m W/(2b))。它们是明确规定的源平均，不是对微带基板或金属横截面的求解。平面螺旋没有真实端面窗，蛇形没有介质基板和地板，鸟笼没有电容或谐振求解。

14、15、17 号不人为补上闭合回流；有向开路径的端点和沿线电流变化对应 rho_ext=div(J)/(i omega)。完整 curl-curl Maxwell 方程保留这个响应，不能使用 div(J)=0 的简化。geometry_current_balance 对开曲线非零是预期结果。交付前核验曾以 psi=r² exp[-i(m phi+kz z)] 做独立分部积分，核对端点和沿线电荷项。

`GeometrySegment.phase_advance` 保留段内线性电流相位，OBJ 另用 `# rf_phase_advance` 注释导出。固定半径的线性相位段用指数乘 sinc 精确积分，跨半径段按径向单元切分后求积。原有 v7 工程缺少新增字段时采用确定的默认值；v8 采用 6 单鞍、7 双鞍形、8 Nagoya III；原 v7 的 6/7/8 自动转换为 7/8/6。

`工程文件/examples/` 保留 17 类几何示例及有限碰撞、正碰撞极限吸收的等离子体示例。十七类几何示例的文件序号与 type 相同；例如 `04_loop.rfproj` 对应 type=4。

### 电流谱怎样与材料响应衔接

同一几何、驱动电流和相位下，给定源谱不随真空/等离子体负载改变。程序将完整源的每个半径位置加载到 Maxwell 方程，材料改变的是求得的 E、B、响应电流和复供功。`K_eff` 是便于查看的径向汇总，不足以重建多半径源的真实场。

`source_mode=q` 描述输入电流谐波，`selected_m` 描述要观察的输出 Fourier 分量；二者不同。某一 m 未被源激发时，场接近零可以是正确的选择规则结果，应先检查源谱，再判断求解失败或材料截止。

## 5. Maxwell 方程、有限元与材料响应

真空和冷等离子体共用 `工程文件/src/maxwell.c`，求解完整圆柱 Fourier 模态全矢量频域 Maxwell 边值问题。材料以完整介电张量进入全局方程。

### 从 Maxwell 方程到求解方程

峰值相量采用 exp(−iωt)，因此 ∇×E=iωB。以 J_ant 表示外加天线电流，材料响应纳入 ε_r，得到

$$
\nabla\times\nabla\times\mathbf E-k_0^2\boldsymbol\epsilon_r\mathbf E
=i\omega\mu_0\mathbf J_{\rm ant},\qquad
\mathbf B=\frac{\nabla\times\mathbf E}{i\omega},\qquad k_0=\frac{\omega}{c_0}.
$$

用相同的模态约定离散矢量旋度，先解 E，再用基函数的解析旋度恢复 B；不把各分量拆成互不耦合的标量波动方程。

### 相容有限元与边界条件

每个普通径向单元的自由度为 `(D_j,P_j,Z_j,P_(j+1),Z_(j+1))`。`Er=D_j`，`r Ephi` 和 `Ez` 分片线性。它包含分片标量势的梯度，保持 curl-grad 关系。轴心首单元按照 `m=0`、`|m|=1`、`|m|>=2` 分别采用 PDF 的正则基；特别是 `|m|=1` 的横向轴上场可以非零，满足 `Er(0)=-i Ephi(0)/m`。

PEC 外壁只消去切向自由度 `Ephi(R)=Ez(R)=0`，保留法向场。材料界面对齐网格，切向 E 通过共享自由度连续，切向 B 和法向有效 D 的匹配由弱式实现并随网格收敛。可以用 `rf_maxwell_evaluate(..., side=-1/+1, ...)` 检查同一界面的双侧迹。B 由基函数的解析旋度恢复，不跨界面或源面对采样数组差分。有限阶离散的 B 切向迹仍有离散误差，不把其有限网格值宣称为精确连续。

内部网格同时包含均匀基础点、材料界面、源面及必要的自适应点。正碰撞简单共振附近按 `ell≈Im(S)/|S0'|` 加密。局部冷等离子体色散的两支都用于限制单元相位和衰减增量，避免只分辨共振层却漏掉 TG 短波。基础单元数增加时，共振层和波长预加密也同步细化。内部上限为 131072 节点；超过时返回明确错误。显示仍使用 `radial_cells+1` 个均匀样本，内部积分不依赖显示样本。峰值指标在内部各单元的双侧端点和内部点估计；极窄层的曲线和热图仍可能受显示采样限制，峰值估计也需要网格收敛。

默认使用 16 点 Gauss 求积，`|m|>12` 使用 32 点。可用 `rf_maxwell_solve_order` 独立改变求积阶数。所有矩阵项都含圆柱权重 `r dr`。矩阵原半带宽 4，选主元后上带宽最多扩至 8；没有稠密回退。对称对角平衡只是数值变量缩放，不修改介电张量和物理源。

后向误差由原始受约束系统计算：`max|Au-f| / max_i(|f_i|+sum_j|Aij uj|)`，超过 1e-8 返回失败。它不能代替场、网格或谱收敛。

### 有限宽度与 17 类规定电流源

`geometry_integrate_source` 对给定等流线做 `du/band_width` 平均，然后沿路径积分 `I exp[-i(m phi+kz z)] dl/(2pi)`。圆柱半径测度与体源中的 `1/r` 已相消。每个源点保留自己的半径，展示谱 `K_eff` 不能用作实际场的集中源。

矩形带的长度和张角同时随宽度位置变化；螺旋和 Nagoya 的两条闭合支路各承载 I/2，共享主腿相加为 I；部分匝、半 Nagoya 和直弦分别保留多半径回流及径向连接段。矩形阵列使用 `spacing/b` 的单元位置，半匝阵列沿完整圆周均布。带宽、整体相位、绕向和电流方向均进入真实源积分。单鞍不再与双鞍形共用同一个源。

常半径段用 sinc 精确积分线性相位；跨径向单元的连接段先在网格节点处分段再求积。宽度方向也按相位梯度细分，避免高波数混叠。源积分和场积分的加密可以分别检查。

新增 13–17 号为轴向多环、平面螺旋、分段多环、鸟笼电流、蛇形电流。开曲线和沿线相位变化允许 div(J) 非零，其源电荷由 rho_ext=div(J)/(i omega) 决定；它们不满足下文仅针对原有闭合源的梯度正交检查，交付前核验改用包含端点及沿线电荷的分部积分。原有全矢量 curl-curl 求解无需假定 div(J)=0。径向网格额外对齐分段环的各个半径。交付前天线专项核验覆盖了 1596 组源谱和 34 次真空/等离子体求解，图和公式见 PDF 第一章新增五类部分。

### 两种材料响应与内部无损参考

`plasma.c` 从物种动量方程 `M_s (nu_s-i omega) v_s=q_s(E+v_s×B0)` 得到冷等离子体张量。相量采用 `exp(-i omega t)`，`Omega_s=q_s B0/M_s` 保留电荷符号，`wp_s²=n_s q_s²/(epsilon0 M_s)`：

```text
epsilon_r = [[S,-iD,0],[iD,S,0],[0,0,P]]
S = 1 - sum wp_s² (omega+i nu_s) / [omega ((omega+i nu_s)²-Omega_s²)]
D = sum wp_s² Omega_s / [omega ((omega+i nu_s)²-Omega_s²)]
P = 1 - sum wp_s² / [omega (omega+i nu_s)]
```

电子与一个准中性离子种类采用独立有效阻尼；密度可均匀、抛物线或高斯。`r>a` 为真空，`r=a` 的材料值取内侧。反转 B0 时 D 反号，S/P 不变；B0=0 时 S=P、D=0；零密度恢复真空。材料响应电流为 `J_pl_hat=-i omega epsilon0 (epsilon_r-I) E_hat`。

界面的“材料响应”只提供以下两项：

- **有限碰撞**（`solve_mode=0` / `--plasma-method finite`）：直接使用输入的电子、离子碰撞率及边缘比；为兼容已有设置也允许两种输入均为零，但此时普通求场仍拒绝内部 S0 共振。
- **零碰撞极限**（`solve_mode=2` / `--plasma-method zero`）：不使用任何输入碰撞率或碰撞边缘比。内部采用均匀正小量 `nu_e=nu_i=eta*omega`，`eta=0.01*2^(-level)`，最多 18 级，保持实驱动频率、密度、磁场、源和边界不变。通过正小量序列求极限；存在内部简单混合共振时先检查 D0/P0 非退化并在层内加密，先积分吸收再取极限。

旧工程或旧等离子体配置中的 `solve_mode=1` 载入时自动转为 2，保留原碰撞输入供切回有限碰撞时使用；保存时只写出 0 或 2。命令行兼容旧别名 `given`（等于 `finite`）以及 `limiting/collisionless/resonance` 和 `--plasma-resonance`（等于 `zero`）。内部解析无损参考标记继续供分支、射线和极限端点检查使用，不作为独立界面求场模式。

延拓每级先比较基础径向网格加密（层内和短波预加密同步），再比较独立的 16/32 点单元求积（|m|>12 时为 32/64 点），然后比较相邻碰撞级的积分吸收和固定层外复 E、cB。容差分别为 0.3%、0.03%、0.3%；延拓相邻级比较连续两次通过（至少计算三个正小量级）才报告成功，最多 18 级。基础径向加密最多 2048 单元，内部节点上限另行控制。任何一项未通过都返回失败，不返回未收敛的末级作为“极限”。当前使用数值正碰撞族，不声称实现了完整复平面 Frobenius 基的任意阶全局匹配。

没有内部简单混合共振时也先运行正小量序列。为避免趋零吸收的相对差一直保持 O(1)，功率差按复源功尺度 `0.5*I0²*|Z_hat|` 与吸收功率的较大者归一；层外复场仍独立检查。相邻级比较连续两次通过（至少计算三个正小量级）后，在独立径向/求积检查后的解析零碰撞端点再核对相同误差门限，通过才返回正则零损耗场；不是一开始直接把碰撞率置零。共振处继续按吸收功率相对差收敛，返回可分辨的正小量级近似，并在 `collision_scale` 中记录 `eta=nu_reg/omega`；正则端点为 0，有限碰撞为 1。退化根、轴心/界面重合根、回旋材料极点及无有限全局匹配极限的情形分别报告；不能把所有谱峰称为 S0 共振。有限正碰撞回旋响应若材料有限，仍可走正常矢量有限元。

局部色散在远离材料极点的正则位置直接使用此正小量族的解析材料极限；零碰撞极限下的根、射线路径与输入碰撞参数无关，传播段的碰撞光学厚度为零。射线在奇异层及 WKB 失效处终止，不据此计算共振层穿越吸收；那一吸收仍由全波极限过程求得。

### 功率和质量检查

材料吸收使用独立物种速度耗散的非负公式。源供功由 FEM 复源内积得到：`dP_src/dkz=-Im(sum conj(u_a) f_a)/(2 omega mu0)`。两者独立计算。无损时供功虚实相消的舍入误差按复功率自然尺度归一，有可分辨吸收时按有功尺度归一；源供功不被吸收值覆盖。

`rf_physics.h` 统一 c0、epsilon0、mu0 并保持 `c0² mu0 epsilon0=1`，避免不同常量来源导致固定能量偏差。吸收总量使用内部单元积分，不由显示网格梯形积分替代，也不额外多乘 2π；内部累计数据保留供求解和核验使用，界面不恢复累计吸收图。

### 对称相消模态的数值处理

某些闭合天线在所选 m、kz 下不激发该 Fourier 分量。例如默认双鞍形的 m=0、单环的 m=±1；源积分可能只剩浮点舍入残余。这不是天线类型不受支持。求解器只对严格为零的装配右端直接返回零场；非零右端即使很小也照常求解，再用原始系统检查后向误差。旧的“近零源直接跳过求解”分支会留下非零 b，却用 E=0 检查 A E=b，误报后向误差约为 1；现已修正，1e-8 门限保持不变。

交付前的对称模态核验覆盖了 12 类天线、m=-1/0/1、真空和等离子体共 72 组，包含零激励的模式；GUI 与 CLI 另复现了默认双鞍形 m=0 的原报错场景。相消模式得到接近零的场和吸收是正确结果，不能自动改 m 后把另一模式的结果冒充原设置。

### 收敛诊断与成功条件的边界

延拓场比较包含六处探针的复 E 和 cB，保留相位并避开共振邻域；它不是整个空间的严格误差上界，也不表示共振峰逐点收敛。Maxwell 原约束系统及库仑电势投影的归一化后向误差以 1e-8 为拒绝门限；独立报告的 `power_balance_error` 不采用适用于所有求解的统一 1e-8 门限。普通求场失败或延拓未收敛不能直接解释为物理上不存在传播波。

## 6. 空间重建、吸收、负载阻抗与收敛

本功能保留轴向无界、背景只依赖半径、外壁为径向 PEC 的基准模型。当前界面的“等离子体单模场”固定一个 `(m,k_z)` 画径向谱量；单 m 的 k_z 带相干重建仍用于“电势波形”、全模式求和的内部步骤及 `--spatial` 命令行。观察窗口和工程中的“显示长度”都不产生轴向端板。

### 使用

在“天线”页设置频率、角向模数 m 和轴向波数 k_z，选择“等离子体单模场”并计算。该栏目合并原来的两个单模式栏目，提供电场幅值、磁场幅值、轴向能流密度、电流幅值、局部吸收、径向壳层沉积、波阻抗幅值七张径向曲线；局部吸收和壳层沉积各保留一个入口。七图来自同一次单波数求解及快照；吸收 q_hat 的单位为 W/m，壳层沉积 r q_hat 为 W，波阻抗 μ₀‖E_hat‖/‖B_hat‖为 Ω。顶部峰值随图切换单位，吸收总量为 dP/dk_z（W·m）。扫描波数范围、m 求和范围及空间窗口不参与这次计算。

“电势波形”使用当前 m 与“扫描”页的 k_z 带宽相干重建库仑规范电势，显示一张“电势虚部波形堆叠”，要求固定有限碰撞材料，使用 z 观察窗口和 z/r 显示网格。它独立更新自己的结果，不覆盖固定 `(m,k_z)` 的吸收栏目。吸收谱和负载阻抗谱在“等离子体波数谱”中查看；多 m、k_z 的空间吸收在“等离子体总场”中查看。下面的相干重建推导、功率归一化和收敛说明针对波形、命令行和全模式内部计算。

命令行例子：

```sh
./工程文件/.build/rf-workbench --spatial \
  --project 工程文件/examples/无限长空间吸收示例.rfproj \
  --output /tmp/absorption.csv --spectrum /tmp/impedance.csv
```

`--impedance` 是同一计算的别名。可覆盖 `--kmin`、`--kmax`、`--nk`、`--zmin`、`--zmax`、`--zpoints`、`--rpoints` 和已有物理参数。空间 CLI 输出 CSV 和 JSON 摘要，SVG 在界面导出。单个波数的真空/等离子体求解也输出阻抗**谱**，单位 Ω m，不能当作完整阻抗 Ω。

### 场、吸收和归一化

求场相量约定为 `exp(i m φ + i kz z − i ωt)`，电流为峰值。对一个 m：

$$
\mathbf E_m(r,z)=\int\frac{dk}{2\pi}\widehat{\mathbf E}_m(r,k)e^{ikz},\qquad
\mathbf J_m(r,z)=\int\frac{dk}{2\pi}\widehat{\mathbf J}_m(r,k)e^{ikz}.
$$

代码先相干叠加三个复数场分量，再由同一固定材料响应构造 J 并计算吸收。正定的物种碰撞损失公式与下式等价：

$$
q_m(r,z)=\frac12\operatorname{Re}\!\left[\mathbf J_m\cdot\mathbf E_m^*\right]\quad[\mathrm{W/m^3}].
$$

不能把吸收谱直接逆变换为 q，也不能把每个 k 的场强平方相加当作局部吸收；两种做法都会丢失波数间干涉。本节的空间求解器一次重建单个 m，其 q 与 φ 无关；多 m 总场已在“等离子体总场”中实现，局部吸收保留 m 间干涉，不能直接相加单 m 的吸收热图。

图表和 CSV 使用：

$$
\frac{dP_m}{dz}=2\pi\int_0^a r q_m\,dr,\qquad
\left.\frac{dP_m}{dr}\right|_{\mathrm{window}}=2\pi r\int_{z_{\min}}^{z_{\max}}q_m\,dz.
$$

$$
P_{m,\mathrm{window}}=\int_{z_{\min}}^{z_{\max}}\frac{dP_m}{dz}\,dz,\qquad
P_{m,\mathrm{band}}=\int_{k_{\min}}^{k_{\max}}\widehat P_m(k)\,dk.
$$

其中 `P_hat=∫ r q_hat dr`，单位 W m。轴向 Parseval 的 `1/(2π)` 与角向积分的 `2π` 相消，所以最后一个公式没有额外 `2π`。有限观察窗口的吸收不必等于带内谱积分。

径向显示网格只负责输出 q/E/J。轴向吸收曲线与总量使用所有 k 的 FEM 网格节点并集，在等离子体内部每个公共单元做 16 点 Gauss 积分；不靠粗显示网格积分窄吸收层。z 积分使用显示网格上的梯形法。`radial_check_error` 比较公共径向求积后的 Parseval 参考值和各谱片 FEM 内部吸收积分，并不检查 k 步长是否足够。

### 相干重建的空间波阻抗（内部与 CLI 数据）

空间求解器仍输出当前单 m、k_z 带相干场的局部幅值比，供内部结果和 CLI CSV 使用。界面的单模式栏目现使用固定 `(m,k_z)` 的径向比值，上述空间数据不再作为该栏的 r-z 图显示。相干场的定义为：

$$
Z_{\mathrm w}(r,z)=\frac{\sqrt{\sum_c|E_{m,c}(r,z)|^2}}{\sqrt{\sum_c|H_{m,c}(r,z)|^2}}
=\mu_0\frac{\sqrt{\sum_c|E_{m,c}(r,z)|^2}}{\sqrt{\sum_c|B_{m,c}(r,z)|^2}}\quad[\Omega].
$$

每个 k 的 B 由原始 FEM 基函数的解析旋度按 B_hat=curl(E_hat)/(iω) 求出，再与 E 使用相同的 dk/(2π) 和 exp(ikz) 因子相干重建。最后才计算两个复矢量范数的比值；不能把各 k 的阻抗或场幅值直接相加。

这个实数幅值比描述包含干涉和近场的相干场，不包含相位，不能视为某一色散分支的复波阻抗，也不是天线的端口负载阻抗 R+iX。天线负载由外加电流与电场的复功计算，在“等离子体波数谱”的“负载阻抗谱”及 CLI 摘要的带内 R/X 中输出。磁场严格为零或比值不能以有限浮点数表示时留空；不添加人为分母或截断实际数值。仅电场为零而磁场非零时，原始值为 0。

旧空间热图入口及其专用 CSV 已移除。当前完整空间场 CSV 包含三个复磁场分量，CLI 同时输出波阻抗与有效性；总场栏目另有第 8 节所述的专用阻抗 CSV。界面单模式径向波阻抗另用 `r_m,selected_m,kz_rad_per_m,Z_wave_ohm,valid`，避免与空间数据混淆。波阻抗和端口负载阻抗均不随给定天线电流的统一幅值或相位变化；相干波阻抗的空间分布会随天线位置平移。

### 阻抗定义与功率守恒

天线电流分布由输入给定，没有求解馈电端口。先定义源供给场的复功率，再按峰值电流平方归一化。代码保留求场的 `exp(−iωt)`，但输出阻抗采用工程 `exp(+iωt)` 约定，**X>0 表示感性**；这需要对复功率取共轭，不能只从吸收功率猜出电抗。

若原始受约束 Maxwell 系统为 `A e=b`，其源内积为 `C=e†b`，则

$$
\widehat P_{m,\mathrm{src}}=-\frac{\operatorname{Im}C}{2\omega\mu_0},\qquad
\widehat Z_m=\frac{iC}{\omega\mu_0 I_{\mathrm{peak}}^2},\qquad
Z_{m,\mathrm{band}}=\int\widehat Z_m\,dk.
$$

因此

$$
\operatorname{Re} Z_{m,\mathrm{band}}=\frac{2P_{m,\mathrm{src,band}}}{I_{\mathrm{peak}}^2}.
$$

源内积含完整规定路径、各半径回流与径向连接段；对开放源也保留端点及沿线电荷对应的响应，不能用展示用的 `K_eff` 集中在一个半径替代。材料吸收独立求积，再与源供功比较。无耗散真空单谱片的实部应为舍入误差量级；电抗通常非零。当前有限碰撞、径向封闭、轴向无限的耗散基准内，带内源供功与等离子体吸收一致。这里没有新增真空体耗散，也没有把场的空间衰减当作损失。

**Z 是当前 m、所选 k 带的等效负载贡献，包含该源分布激发的真空与等离子体场。它不是完整天线端口阻抗**：尚未对所有角向模式求和，不含导体欧姆损耗、馈线、匹配网络、端口电流的自洽重分布，也未采用开放径向辐射边界。理想细线或未充分解析的带宽源可能使高波数/高 m 自场电抗收敛很慢，甚至需要有限导体截面的正则化；不能把任意截止下的 X 当作已收敛的实际端口电抗。

### 波数离散、周期重复与收敛

空间重建采用 **中点等权求积**：`Δk=(kmax−kmin)/nk`，`kj=kmin+(j+1/2)Δk`，场权重为 `Δk/(2π)`。原有“波数扫描”仍是含端点的网格，点位置不同是有意的。中点规则使完整离散周期内的功率与 `Δk Σ P_hat` 严格满足离散 Parseval，避免梯形端点权重在场平方后再次被平方而制造归一化偏差。

离散场的模平方重复周期为 `Lrep=2π/Δk`；它是傅里叶求积的数值重复，不是装置的物理周期边界。程序拒绝宽于这个周期的观察窗口，并要求 `Δz≤π/(kmax−kmin)` 以解析 q 的干涉频率；这只是必要的采样条件，仍需加密 z 核对积分和吸收位置。

摘要同时报告：

- `power_balance_error`：独立源供功与谱吸收的相对差。
- `radial_check_error`：公共径向求积与原 FEM 吸收积分的相对差。
- `edge_ratio`：观察窗口两端最大 dP/dz 与窗口内峰值之比。
- `band_edge_fraction`：k 带两端各约 5% 节点贡献的吸收占比。
- `impedance_edge_fraction`：同一边缘区域的 `Σ|Z_hat|/Σ|Z_hat|全带`，用模避免正负抵消。

这些指标不能替代收敛检查。弱碰撞下窄传播谱峰可能落在采样点之间，即使功率守恒很好、谱尾很小，k 积分也可能不准确。保持 k 范围先加密 nk，再扩展范围并保持足够小的 Δk；分别比较吸收峰位置、dP/dz、吸收 W 和 R/X。扩大 z 窗口时同步增加 nk，使重复周期足够大，并查看端部是否衰减。研究轴向非均匀背景、端部反射或闭合全环传播，需要相应的其他轴向模型，不能只扩大本模型的显示窗口。

只允许选择“有限碰撞”、正密度且至少一种碰撞率为正的固定材料；当前空间重建不支持“零碰撞极限”。各谱片独立通过极限检查的正小量级可能不同，不能把末级场直接拼接成已收敛的空间总场；一致的空间极限还需在同一正小量级重建并检查整个序列，无损实轴谱极点也需因果处方。这些情况明确拒绝，不能靠把失败谱片填零得到空间图或辐射功率。

### 验证与示例数值

交付前的空间核验用薄环处 E 与外加电流的直接做功独立核对了复阻抗及感抗符号，并检查 E/J 材料做功、完整周期 Parseval、天线平移、整体相位、电流平方缩放、窗口变化不影响阻抗，以及失败/取消的内存生命周期。当时的 CLI 回归检查了物理单位、矩形 CSV、中点 k 和错误参数；GUI 回归检查了七张单模式图、电势虚部与原始 CSV 一致、统一显示增益、零电势、悬停基线、显示抽样、CSV/SVG、停止与保存。相关自动化核验源码和构建目标不随本次交付保留。

### 空间采样范围与浮点分辨率

空间重建仅接受有限碰撞、正密度、至少一种碰撞率为正的固定材料；电势波形和多 m 总场也遵守这一限制。单 m 空间 CLI 和电势波形的径向显示默认到等离子体半径 a，总场显示特意延伸到容器半径 R。径向显示范围与内部全波求解的 PEC 边界不是一回事。

UI/CLI 共用波数点数 nk 为 3–401；底层空间 API 的能力范围为 3–4097，不代表界面允许输入该上限。空间 nr 为 17–2049、nz 为 3–1001，且 nr×nz≤500000。除窗口周期与轴向采样约束外，实际 r、z、k 节点还必须在 double 精度下严格可区分；连续区间看似有效但离散节点重复时也会拒绝计算。

## 7. 库仑电势与波形堆叠

打开 `工程文件/examples/二维波场堆叠示例.rfproj`，选择“电势波形”，图示为“电势虚部波形堆叠”。它固定频率与 m，对扫描 k_z 带相干积分，横轴 r、纵轴为 z 基线，起伏为 Im Φ（V）。原来的三个 Re E 分量堆叠入口已替换。

全电磁场不能一般地写成 E=−∇Φ，因此须先规定规范。这里采用外壁电势为零的库仑规范：

$$
\mathbf E=-\nabla\Phi+i\omega\mathbf A,\qquad\nabla\cdot\mathbf A=0,\qquad\Phi(R)=0.
$$

每个 `(m,k_z)` 的电势满足标量泊松问题

$$
\left[\frac1r\frac{d}{dr}\left(r\frac{d}{dr}\right)-\frac{m^2}{r^2}-k_z^2\right]\widehat\Phi
=-\left[\frac1r\frac{d(r\widehat E_r)}{dr}+\frac{im}{r}\widehat E_\phi+ik_z\widehat E_z\right].
$$

弱式为 ∫r ∇v\*·∇Φ_hat dr=−∫r ∇v\*·E_hat dr。它使用原始 Maxwell 网格和解析有限元场，不对显示采样差分，也不跨材料界面直接差分电场。界面电荷由弱式右端统一包含。轴心按 |m| 幂次正则；m=0 的首单元为偶函数，m≠0 时 Φ(0)=0。外壁 Dirichlet 条件固定电势参考，m=k_z=0 也无需除零或增加人工小量。电场的横向感应部分仍属于矢势 A，提取电势不会改变 Maxwell 场、吸收和功率。

谱电势单位是 V·m；使用与 E/B 一致的中点权重恢复为 V：

$$
\Phi_m(r,z)=\sum_j\widehat\Phi_m(r,k_j)e^{ik_jz}\frac{\Delta k}{2\pi}.
$$

图中固定 φ=0，显示复电势的虚部，不是电势模长或电场虚部。改变天线整体相位会改变该虚部快照。取若干原始轴向采样位置 z_j，每条曲线按下式放置：

$$
x=r,\qquad y_{\mathrm{display}}=z_j+g\,\operatorname{Im}\Phi_m(r,z_j).
$$

纵轴的 z_j 是波形基线位置，起伏高度是电势的显示位移，不能作为射线坐标。整张图共用一个显示增益 g，单位 m/V；不对各条曲线单独归一化，因而仍能比较波包随 z 的强弱。令 Lz 是轴向窗口宽度、M 是全部原始网格上的 max |Im Φ|，s 为图上选择的起伏倍率（0.5、1、2、4），选择

$$
g=\frac{0.06L_z\,s}{M}\quad(M>0),\qquad g=0\quad(M=0).
$$

波形计算会将左侧 z 点数提高至至少 401（受总网格 500000 点上限限制，已有更密设置则保留），再实际重算并冻结快照。至多显示 501 条原始 z 切片，均匀选择索引并保留首尾，每条显示全部径向样本；不通过插值制造额外曲线。默认用更细的线描绘密集波形，每 25 条强调一条。增益独立于条数，因此加密线条不会压小起伏；“起伏倍率”按钮仅改变显示，不修改计算参数、原始数据和 CSV。图顶给出实际条数及增益。悬停报告真实 z 基线、r 和 Im Φ（V）。

GUI 波形使用专门的电势任务：各 k_z 的 Maxwell 与库仑电势求解保持原样，只重建观察网格上的 Φ，不执行波形不需要的空间吸收高阶径向积分。该任务与完整空间求解在共同观察点的复电势一致。波形专用 CSV 为 `z_m,r_m,Phi_Coulomb_re_V,Phi_Coulomb_im_V,selected_m,potential_backward_error`，不混入未计算的吸收量或显示位移。CLI `--spatial` 和全模式任务继续执行原有完整场、吸收和功率积分；完整空间 CSV 在原有列之后追加复电势两列，E/B/J 及功率列顺序保留。

该示例采用 13.56 MHz、m=1、氩等离子体、5 mT 磁场和有限螺旋源，展示本程序模型的纵向电势。它与论文理论图的 Im Φ 采用同类绘图量，但没有改成论文的准静电边界激励问题；全电磁库仑电势仅在准静电极限下与相应静电解一致。它也没有把 helicon/TG 等分支逐一分离。

实现入口：`maxwell.c: rf_maxwell_prepare_potential/rf_maxwell_evaluate_potential` 求解和取样标量电势；`spatial.c: rf_spatial_begin_potential` 启动电势专用重建，`rf_spatial_begin` 启动完整空间场求解；`rf_gui_spatial.h` 读取电势虚部；`rf_gui_views.tcl` 处理统一增益、绘制及查询。交付前核验曾制造纯梯度场，检验恢复出的复电势、壁面参考、轴心和 k_z=0；纯横向场检验提取结果为零。当时还独立对照了逐 k 重建、源相位旋转、电流缩放、轴向平移及电势专用任务与完整任务的一致性。

### 怎样读波形图

先定位一条曲线的真实 z 基线，再沿横轴 r 观察其电势虚部起伏；同一张图共用增益，所以能够比较不同 z 位置的相对强弱。增加曲线密度用于观察波包结构，改变起伏倍率仅改变画法。若要获得数值，应使用悬停或 CSV 中的 Im Φ，不能把画布上的位移当作电场、传播距离或射线路径。

## 8. 等离子体总场：多 m 相干叠加

“等离子体波数谱”后面的“等离子体总场”保留固定频率，把指定范围内的所有整数 m 与选定 k_z 带重建为物理空间场。左侧“扫描”页提供 m 下限、m 上限、观察方位 φ（rad）、z 窗口及 z/r 点数；k_z 采用该页共用范围和采样数。m 当前允许 -16 到 16；上下限相同表示只保留一个 m。“全模式”不表示已经包含无限多个模式，需要扩大 m、k_z 范围并加密采样验证收敛。

### 相干场与物理单位

对 F=E、B、J_pl，使用同一峰值相量约定 exp(-iωt)：

$$
\mathbf F(r,\phi,z)=\sum_{m=m_{\min}}^{m_{\max}}e^{im\phi}
\int_{k_{\min}}^{k_{\max}}\widehat{\mathbf F}_m(r,k_z)e^{ik_z z}\frac{dk_z}{2\pi}.
$$

各模式由同一天线几何和给定驱动电流独立求解，不人为指定分支功率、补共轭模式或重复计入负 m。磁场由每个原始 FEM 解的解析旋度得到。材料在 φ、z 方向均匀，因此响应电流的线性材料算子与模式重建可交换。

先叠加复振幅，再计算矢量幅值。禁止直接求和 |E_hat|、|B_hat| 或不同模式的吸收来替代截面总场结果。电场、磁场、电流三图各提供“总幅值、r 分量、φ 分量、z 分量”的热图切换，分量显示其复数幅值；单位分别为 V/m、T、A/m²。径向显示延伸到容器半径，包括等离子体外的真空区；界面和源面取 FEM 内侧迹。

### 七张图

| 图      | 物理量                         | 单位   |
| ------ | --------------------------- | ---- |
| 电场幅值   | $\sqrt{\sum_c\lvert E_c\rvert^2}$ 或单个分量幅值         | V/m  |
| 磁场幅值   | $\sqrt{\sum_c\lvert B_c\rvert^2}$ 或单个分量幅值         | T    |
| 轴向能流密度 | ½Re(E_r B_φ\*−E_φ B_r\*)/μ₀ | W/m² |
| 电流幅值   | $\sqrt{\sum_c\lvert J_{\mathrm{pl},c}\rvert^2}$ 或单个分量幅值      | A/m² |
| 局部吸收   | q=½Re(J_pl·E*)，固定所选 φ       | W/m³ |
| 径向壳层沉积 | r∫₀²π q(r,φ,z)dφ            | W/m² |
| 波阻抗幅值  | μ₀‖E_total‖/‖B_total‖       | Ω    |

场、局部吸收和波阻抗使用可调 φ 的 r-z 截面，壳层沉积作完整圆周积分。能流允许正负，正值表示沿 +z，负值表示沿 -z；使用对称的蓝—白—红线性色标，其余非负图使用四个数量级的对数颜色。颜色的显示下限不修改 CSV 数值。吸收继续使用正定物种碰撞损失公式计算，避免弱损耗下复功相消产生负值。

总场波阻抗按所选 φ 截面的完整复矢量计算：

$$
Z_{\mathrm w}(r,\phi,z)=\mu_0\frac{\sqrt{\sum_c|E_c(r,\phi,z)|^2}}{\sqrt{\sum_c|B_c(r,\phi,z)|^2}}.
$$

分子和分母中的 E、B 都已经完成 m 求和与 k_z 相干积分，所以仍保留模式间干涉；各模态波阻抗不能直接求和。磁场严格为零或比值不可表示时，该位置留空，不添加人为分母。此量只有局部幅值比，不含相位，不等于天线端口负载阻抗。新图专用 CSV 记录 z、r、φ、Z_wave_ohm、valid、m 上下限和 k_z 上下限；其他六图的 31 列总场 CSV 保持原有顺序。

### 壳层沉积为何与观察 φ 无关

令 E_m(r,z) 已对 k_z 相干重建，由单 m 场计算的局部吸收为 q_m(r,z)。材料与 φ 无关，由圆周谐波正交性：

$$
G(r,z)=r\int_0^{2\pi}q(r,\phi,z)\,d\phi=2\pi r\sum_m q_m(r,z)=\frac{d^2P}{dr\,dz}.
$$

这一步消去不同 m 的交叉项，但每个 q_m 仍保留不同 k_z 的干涉。一般不能用固定 φ 的 2πr q(r,φ,z) 替代 G。G 仍是一张 r-z 图，单位 W/m²；再沿 z 观察窗口积分得到 dP_window/dr（W/m），沿 r 积分得到全圆周窗口功率（W）。各单 m 的轴向吸收积分使用原始 FEM 公共网格的高阶求积，因此顶部窗口功率不依赖粗径向显示网格的梯形积分。

完整 z 空间、连续且收敛的谱下，Parseval 给出 P=Σ_m∫P_hat_m(k_z)dk_z。当前离散 k_z 重建具有重复周期 2π/Δk，整周期的 z 积分也用于独立校验；有限窗口功率一般不等于带内谱积分。

### 算法、诊断与验证

求解器逐个 m 调用固定有限碰撞的空间求解器；每个 m 对 k_z 采用中点求积，相干重建三个复电场、磁场和响应电流分量。该 m 完成后乘 exp(imφ)，累加到总场，同时累加壳层沉积 2πr q_m；随即释放该 m 的谱场，避免同时保存所有 m 的全部 FEM 解。所有 m 完成后才由总场计算截面局部吸收和能流。当前不混用逐波数极限吸收延拓得到的场。

每个原有空间步骤、累加径向行和最后计算径向行之间均返回事件循环，可以停止；停止或失败保留上一次完整结果，不发布缺少某个 m 或 k_z 的结果。参数在任务开始时冻结，CSV 保留该次 m/k_z 范围、φ 及所有复 E/B/J 样本、幅值、带符号能流、局部吸收和壳层沉积；SVG 导出当前图与分量。窗口不是端板，也不会改变外加天线电流。

交付前的全模式核验独立比较了各单 m 解的复数相干组合、J·E* 与正定吸收、带符号能流，以及七个角度的圆周积分与壳层公式；检查全周期 Parseval、天线和观察方位共同旋转的协变性、单 m 极限和取消任务的数据所有权。当时的 GUI 回归覆盖了七张图、全部幅值分量、总场 E/B 与波阻抗的独立数值核对、磁场节点及小分母、CSV 单位与样本、正负能流色标、参数持久化、快照冻结和停止。

### 完整局部色散、Q 与四个候选径向解

局部平面波的无源方程为 `[ε_r+n nᵀ−n²I] E=0`，其中 n=k/k₀。在轴向磁场下令

$$
Q=\frac{k_r^2+k_\phi^2}{k_0^2},\quad k_\phi=\frac mr,\quad N=\frac{k_z^2}{k_0^2},
$$

则求根多项式为

$$
S Q^2-\big[(S+P)(S-N)-D^2\big]Q
+P\big[(S-N)^2-D^2\big]=0,\qquad
k_r=\pm\sqrt{k_0^2Q-\frac{m^2}{r^2}}.
$$

Q 是无量纲的垂直折射率平方，不是吸收功率、品质因数或另一个独立输入。两支 Q 各配两个 k_r 符号，通常得到四个候选解；根合并、退化或材料奇点处需单独处理。真空中的重根对应两种独立横向极化。A/B 只用于连续跟踪根，正负号也不自动代表向内/向外能流。

### helicon、TG 与 ICRF 快/慢波命名

`branches.c` / `branches.h` 复用 `rf_plasma_material`，直接求完整冷介电张量波矩阵的两支 `Q=(kperp/k0)^2` 和各自 `±kr`，其中 `kr²=k0²Q-m²/r²`。A/B 是按根距离与极化重叠延续的编号，不预设所有频率下都同时存在 helicon、TG 和 ICRF 快/慢波四种物理波名。

图例保留 A/B，并标注发射半径 r0 处的 helicon 型、TG 型、ICRF 快波型、ICRF 慢波型、混合/近合并、待判定或真空；悬停显示当前位置的局部判定。识别只添加诊断元数据，不改变求根、传播状态、群速度或轨迹。以 Chen & Arnush (1997) 的电子惯性参考关系 `delta*beta²-|kz|*beta+kw²=0` 匹配完整无碰撞根的总波数，其中 `delta=omega/|Omega_e|`、`kw²=delta*omega_pe²/c²`。采用保守窗口 `10|Omega_i|<=omega<=0.1|Omega_e|`、`omega>=3omega_LH`、`omega_pe>=3|Omega_e|`、`kz!=0`；近似 `omega_LH²=|Omega_i Omega_e|/(1+Omega_e²/omega_pe²)` 仅用于命名筛选。归一化判别式 `Δ=1−4δ k_w²/k_z²` 大于 0.05，根弱损耗且参考 Q 为正实数、极化有效，才匹配两个实参考根；相对偏差须不超过 20%，对数距离的差须至少 ln(1.25)，TG 型另需纵向极化份额 >=0.8。纵向份额大并非 TG 的充分条件。门限是减少误标的算法选择，不是波存在边界；“待判定”不等于不能传播，“混合”也不表示已计算模式转换。径向与射线 CSV 末尾均追加 `wave_type,wave_match_error,wave_reason`。详细公式及参考算例见 PDF 第五章。

ICRF 命名在 `0<omega<=5|Omega_i|`、`omega<=0.1|Omega_e|` 且无碰撞参考 `P<0` 时启用。固定参考 `S,D,N=(kz/k0)^2`，沿 `P -> P/eta`、`eta:0+ -> 1` 延续；有限极限根 `QF -> ((S-N)^2-D^2)/(S-N)` 标为快波，发散极限根 `QS ~ P*(S-N)/(eta*S)` 标为慢波。检查整个延续区间的二次判别式是否保持非退化，以解析连续的平方根符号恢复完整参考根，并唯一匹配原 A/B 分支；不按 `|Q|` 大小命名。截止、负 Q 或几何径向倏逝可以保留快/慢波归属，射线条件另行检查；强损耗、不可解极化、根合并或无法唯一匹配时保留明确原因。命名窗口和数值门限不改变求根或真实材料响应，慢波也不是新增热声学/Bernstein 分支。CSV 类型新增 `icrf_fast_like/icrf_slow_like`；其 `wave_match_error` 为完整参考 Q 的归一化根距离，与 H/TG 的近似总波数相对偏差定义不同。

“更多 → 示例：离子回旋快慢波识别示例”采用氢离子、1.5 MHz、0.2 T、均匀密度 1e21 m^-3、m=1、kz=85 rad/m、r0=0.15 m。发射处正实部根约 87.19068/2464.57935 rad/m，标为快/慢波型，得到四条双向射线；kz=0 时慢支仍有标签，但处于倏逝状态。

### Hamilton 方程、自适应算法与停止条件

本模块保持现有圆柱设置：背景只依赖 r，均匀轴向磁场，轴向无界，外壁 PEC，冷电子与单离子模型。静态、轴对称、轴向平移不变使 f、m、kz 都沿射线守恒；不改变几何与材料模型。

在右侧“色散与射线”栏目计算；左侧独立“射线追踪”参数页提供以下设置：r0、z0、phi0_deg、群速度向内/向外/双向、相对容差、最大步长、最大路径与最大步数。可打开 `工程文件/examples/指定起点射线示例.rfproj`：r0=0.15 m、z0=0、phi0=0，现有抛物线密度，f=13.56 MHz、m=1、kz=10 rad/m。每个通过筛选的根从同一位置发射；不再从每个可传播区间的中点自动播种。存在根与实际发射是两种结果，拒绝发射的原因单独记录。

以无碰撞参考色散函数 𝒟₀ 为 Hamilton 函数，固定 m、kz；这里的 𝒟 与介电张量分量 D 区分：

$$
\dot r=-\mathcal D_{k_r}/\mathcal D_\omega,\quad \dot z=-\mathcal D_{k_z}/\mathcal D_\omega,\quad
\dot\phi=-\mathcal D_m/\mathcal D_\omega=v_{g,\phi}/r,\quad \dot k_r=\mathcal D_r/\mathcal D_\omega.
$$

频率导数保持物理波矢不变，包括材料频散和 k0=omega/c 的变化。径向导数保持 kr、m、kz 不变，包括 kphi=m/r 的几何变化；材料导数由现有均匀、抛物线、高斯密度剖面的解析导数给出。

实际积分以物理路径 s 为自变量，令 V=|vg|，推进六个变量 `(r,z,phi,kr,t,tau)`：

$$
\frac{d(r,z,\phi,k_r,t,\tau)}{ds}
=\left(\frac{v_{g,r}}V,\frac{v_{g,z}}V,\frac{v_{g,\phi}}{rV},
\frac{\mathcal D_r}{\mathcal D_\omega V},\frac1V,2\operatorname{Im}k_r^{\rm actual}\frac{v_{g,r}}V\right).
$$

其中实际复根使用当前材料响应：有限碰撞取输入碰撞剖面，零碰撞极限取正则材料解析极限；轨迹使用匹配的无碰撞参考。仅接受弱损耗、根分离、极化有效、WKB≤0.1 的部分。`P/P0=exp(-tau)` 为不含聚焦的相对射线管功率，不是场强平方，也没有计算天线对各分支的耦合比例。

自适应采用 RK4 步长加倍比较：一个整步与两个半步之差除以 15，结合六个变量的量纲尺度估计误差。试探终点的 kr 独立演化，然后求解同一参考分支校正；校正量同时参与误差验收。匹配使用实际/参考根距离及极化重叠。无法通过误差或物理筛选时拒步、缩步；不在 RK 子步跨过材料界面。积分最大步长与输出点一致受限，径向诊断网格不控制轨迹精度。群速度的频率差分避免跨越回旋极点，并采用两档差分步长检查一致性。

界面将色散与射线合并为一个栏目，保留五张径向诊断图：径向波数实部、径向波数虚部、分支传播状态、群速度和几何光学适用性，以及三张实际射线图：绝对 z-r 投影、方位角、P/P0。群速度同图显示四支的 r/φ/z 分量，可按分量和分支勾选，颜色区分分支，实线/虚线/点线区分分量。极化纵向份额、根间距、极化残差、参考 kr 和校正前色散残差保留在内部计算与 CSV 中，不单独绘图。方位角和 P/P0 以路径 s 为横轴；箭头沿时间递增，悬停报告终止原因。材料界面两侧和独立发射区间在曲线上断开，CSV 保留全部四个候选解及缺失原因。轨迹 CSV 按 `ray_id` 和时间排序。GUI 按当前选择的图导出径向根表或沿程轨迹表；CLI 的 `--output` 导出完整径向根表，`--rays` 导出独立自适应轨迹表，包含起点、时间、路径、参考/实际波数、单位极化、WKB、相对功率、校正前残差、kr 校正量及终止原因。径向根表的旧 ray\_* 字段保留为无轨迹值，不再用它混装自适应轨迹。

### WKB、波型和发射资格分别判断

程序使用的局部几何光学指标为

$$
\mathcal W=\max\left(\frac{|dk_r/dr|}{|\operatorname{Re}k_r|^2},
\frac{1}{|\operatorname{Re}k_r|\,r}\right)\le0.1.
$$

第一项检查局部径向波长相对于背景变化是否足够短，第二项检查径向波长相对于柱坐标曲率尺度是否足够短。接近转向点、轴心或奇异层时，该条件可能失效。诊断图的 WKB 由径向样本估计；射线积分在实际半径处检查，不靠加密诊断图来“延长”轨迹。

波型标签只回答局部根如何匹配参考分支；传播状态回答径向根是否传播、阻尼是否足够弱；发射资格还检查起点、群速度、根分离、极化和 WKB。因此“快波型”“TG 型”不保证存在可追踪轨迹，“待判定”也不等于没有色散根。改变密度可能移动截止、转向或混合共振层，轨迹条数应从起点状态和拒绝/终止原因解释，不能强制给每条分支补一条线。

均匀背景中的路径在 Cartesian 坐标可以是直线，但投影到 r、φ 后会出现几何变化；径向非均匀背景则可能折射。图上的线条是能量传播路径，电势波形中的振荡才表示相量场的空间结构，二者用途不同。

有限碰撞下，向内能流的有向根可以有负的 Im k_r；沿程耗散使用 `dτ/ds=2 Im(k_r) dr/ds`，与传播方向共同决定正的被动衰减，不分别取绝对值。零碰撞极限的正则传播段 τ=0，不据此估计奇异层的穿越吸收。

### 内部状态编号与 CSV 有效性字段

分支 CSV 的 `state` 字段保存下表中的状态名，对应源码内的 0–5 状态编号。它描述局部传播状态；波型名称和射线发射资格另行记录。

| 编号 | 状态名 | 含义 |
| --- | --- | --- |
| 0 | `propagating` | 通过局部传播及弱损耗筛选；射线还须通过 WKB、极化和群速度检查。 |
| 1 | `evanescent` | 无碰撞参考中的径向倏逝或转向。 |
| 2 | `strong_damping` | 不满足弱损耗参考射线条件。 |
| 3 | `degenerate` | 非真空分支靠近，孤立分支解释失效。 |
| 4 | `singular` | 色散根不有限，或无可用的无碰撞参考。 |
| 5 | `material_error` | 回旋极点等使介电张量无有效有限值。 |

`valid` 表示实际复根有限，`ray_eligible` 表示通过射线筛选，`reason` 保存筛选结果。群速度、极化、WKB 和轨迹还各自记录有效性，因此 `valid=1` 不保证 `ray_eligible=1`。波型字段的说明见本节前面的命名规则。

### 为什么谱量的单位不同

采用峰值相量 exp(-iωt)，轴向逆 Fourier 变换为 ∫dk_z/(2π)，因此固定 (m,k_z) 的场谱比空间场多一个长度量纲：

| 物理量 | 固定 (m,k_z) 的谱单位 | 相干空间重建后的单位 |
|---|---|---|
| 电场 | V | V/m |
| 库仑规范电势（外壁 Φ=0） | V·m | V |
| 射频磁场 | T·m | T |
| 等离子体响应体电流密度 | A/m | A/m² |
| 外加面电流的谱 K、径向汇总 K_eff | A | 不与响应体电流混用 |
| 局部吸收双线性量 | W/m | W/m³ |
| 由 E、B 构造的轴向能流双线性量 | W | W/m² |

记谱场双线性能流量为 T_z=Re(E_hat×B_hat*)_z/(2μ₀)，则代码中的截面量为 F_z=2π∫r T_z dr，单位 W·m²。它不是实际空间截面功率 W，也不是先求空间能流再直接 Fourier 变换的结果。

吸收采用另一项已经完成 Fourier 归一化的功率定义：P_hat_abs=∫r q_hat dr，单位 W·m。r q_hat 的单位为 W；对 dr 积分后仍是功率谱 W·m，再对 dk_z 积分才得到 W。不要因纵轴恰好写 W 就把一个曲线点当作有限壳层的实际功率。

- 旧版径向 CSV 的 Er_re 等字段是模态谱量；空间 CSV 的 Er_re_V_m 等字段是实际空间量。此处保留原列名兼容性，读文件时应按所属求解类型解释。

### 新算例的收敛顺序

1. 固定物理参数和谱截断，增加径向基础单元及源/场求积阶数，先确保单个谱片能稳定求解。
2. 固定 k_z 区间，增加采样数，检查窄峰、吸收积分及 R/X；再扩大区间并保持足够小的 Δk。
3. 需要总场时扩大 m 范围，比较场幅值、局部吸收与完整圆周功率；检查正负 m 的实际源激励，不能自行补共轭。
4. 重建空间图时检查 Δz、数值重复周期与窗口端部，分别核查局部结构、窗口功率和带内谱功率。
5. 射线独立收紧容差与最大步长，核对终止原因；加密径向诊断图不等于提高轨迹积分精度。

### 常见结果如何理解

| 现象 | 首先查看 |
|---|---|
| 某个 m 的场接近零 | 该模式的真实源谱、对称选择规则和源半径分布 |
| 只出现一条或没有射线 | 指定起点处的候选根、能流方向、弱损耗与 WKB，以及拒绝原因 |
| 改变很少的密度后轨迹消失 | 截止/转向/奇异层位置及起点资格，而非只比较曲线外观 |
| 电阻稳定但电抗仍变化 | k_z 与 m 自场谱尾、有限电流带宽和径向分辨率 |
| 总场热图随 φ 变化而壳层量不变 | 前者保留模式干涉，后者已经全圆周积分 |
| 波形倍率改变但 CSV 相同 | 倍率只改变统一显示增益，原始复电势没有重算 |
| 单模图的单位看起来不同于常见场单位 | 当前显示的是谱场；按第 10 节区分谱量和物理空间量 |

### 构建依赖与自动生成文件

数值内核使用 C11 及其复数/数学函数；平台文件层在 Windows 使用 Win32/宽字符 CRT，在 POSIX 平台使用对应系统文件接口，GUI 依赖 Tcl/Tk。macOS 构建和打包使用 Make、Shell 与 AWK；Windows 原生构建由 PowerShell 直接调用 MinGW-w64 UCRT Clang/GCC 和资源编译器，不依赖 make 或 AWK。程序构建和主文档编译不依赖 Python，主文档编译另需 XeLaTeX/latexmk。macOS 的 `runtime`、`print-config` 等子目录目标使用 `make -C 工程文件 目标`。常用命令见[快速开始](#quick-start)，历史核验和本轮平台检查见[验证范围与交付检查](#validation)。

macOS 默认使用 `deps/macos-arm64.zip` 中固定版本的 Tcl/Tk 8.6.18，通过 `build/macos/prepare_runtime.sh` 按摘要展开并复用缓存；`make runtime` 则从校验过 SHA-256 的上游源码重建依赖压缩包。Linux 或自定义安装可设置 `TCL_CFLAGS` / `TCL_LIBS`，纯 CLI 使用 `make -C 工程文件 GUI=no`。`.build/config` 记录编译器、编译/链接选项与运行库配置；选项切换时使相应对象文件重新构建，避免沿用另一种配置的 GUI 对象。

macOS 的 `build/embed_tcl.awk` 将 `ui/rf_gui_views.tcl`、`ui/rf_gui.tcl` 嵌入自动生成的 `.build/rf_gui_script.h`，Makefile 管理依赖，所有对象文件和可执行文件也写入 `.build/`。Windows PowerShell 以 UTF-8 字节的八进制转义生成同名头文件，并将它放在本次构建的独立暂存目录；GUI 通过头文件搜索顺序读取本平台生成物，不混用另一平台旧头文件。应修改 Tcl 源文件，不手工编辑生成头文件。macOS `make clean` 删除对象文件、源码可执行文件、生成头文件和配置；根目录清理还删除 `tmp/` 派生数据，再次构建会按依赖生成所需文件。

`make app` 从空暂存目录组装 macOS 程序、示例、Tcl/Tk 脚本、动态库及许可，验证签名和参数后更新根目录应用与交付 ZIP。Windows `build/windows/build.ps1` 同样先在独立目录完成全部编译、资源链接、DLL 闭包检查和压缩，再发布运行目录与 ZIP；未知的非系统 DLL 必须随包提供，不能依靠构建机中偶然存在的 DLL。两端都保留源码依赖与独立运行包各自所需的副本。源码构建完成不等于应用已更新，查看正式包前需执行相应平台的打包入口。自包含主 LaTeX 和编译中间文件的维护规则见[主文档维护](#project-maintenance)。

### 参数状态、求解与内存所有权

`main.c` 将命令行解析、项目载入与覆盖校验、具体计算命令分开；`rf_tk_gui.c` 按几何、源谱、真空和等离子体分别构造结果，统一管理 Tcl 结果容器。图表直接读取求解器拥有的场样本，复制到 Tcl 数值后即可释放原解。

`project_io.c` 的各组 `StoredField` 表集中维护工程、材料、射线以及空间/兼容字段，读取、查重与保存共用定义。新增持久化参数时同时考虑旧文件的默认值及字段完整性。文本逐行解析共用一份可修改副本；保存统一经临时文件关闭和改名提交。解析或写入失败须保留调用者状态及原文件。

`rf_platform.c` 集中维护平台文件语义：Windows 严格将 UTF-8 转为 UTF-16，以宽字符文件接口和 `CreateFileW(CREATE_NEW)` 创建同目录唯一临时文件，使用 `MoveFileExW` 覆盖提交；POSIX 保持 `mkstemp/rename`。所有项目与导出入口使用同一层，错误通过现有返回值和 `errno` 传播，不直接在求解器中混入 ANSI/宽字符路径判断。`main.c` 在 Windows 从宽命令行取得 UTF-8 参数，GUI 从实际程序位置查找 DLL 配套脚本，不依赖当前工作目录。

`Options` 保存模式范围、空间采样参数及旧材料配置的 `nk/kmin/kmax` 兼容元数据；实际真空、等离子体和空间计算共用 `WorkbenchProject.nk/kmin/kmax`，不读取这三个旧字段来确定扫描范围。旧文件中未实现的批量扫描与比较字段只在读取时检查数值语法并丢弃，不进入实时状态，也不再写回。材料响应统一使用 `FINITE_COLLISION`、内部 `LOSSLESS_REFERENCE` 与 `ZERO_COLLISION_LIMIT` 三个明确枚举名，界面仍只有有限碰撞和零碰撞极限两项。

`maxwell.c` 按装配与源加载、约束、平衡求解、原系统残差、功率积分分步执行；`plasma.c` 将固定碰撞级的网格/求积收敛与外层碰撞延拓分开。拥有内部网格和系数的结果只转移一次所有权，失败路径统一释放。修改这些流程时保留公式注释与独立功率检查，并按第 11 节的历史参考范围重新建立相应验证；交付中的构建与参数检查不能替代这些独立验证。

### 格式与注释约定

根目录 `.clang-format` 统一自有 C 源码和头文件的格式，使用四空格缩进，展开短条件和循环，保留物理注释。格式工具使用 clang-format 18；第三方依赖压缩包、用户依赖缓存及自动生成的 `.build/rf_gui_script.h` 不参与格式整理。

### 交付前验证结果

- 正常优化构建的六套数值回归：核心、17 类天线、Maxwell、单 m 空间重建、全模式重建、分支与射线；另通过 CLI 和原生 GUI 工作流回归。天线套件包含 1596 项独立源谱检查及 34 次真空/等离子体求解。

### 本轮 Windows/macOS 适配与交付

本轮继续使用同一组物理方程、给定电流模型和 Fourier 归一化，新增两平台共享的文件边界与各自的构建/启动流程：

- 文件操作集中到 `rf_platform.h/.c`：Windows 以严格 UTF-8→UTF-16 转换、宽字符文件接口、独占临时创建及覆盖式系统提交处理工程和导出；POSIX 继续使用既有文件语义。失败路径仍保留原有可用工程。
- Windows 从宽命令行构造 UTF-8 参数；GUI/CLI 两个程序共用内核，分别使用窗口和控制台子系统。GUI 按程序所在位置加载 DLL 配套脚本、示例及平台字体/快捷键；启动失败提供错误弹窗。

- Windows 构建脚本锁定 llvm-mingw UCRT 与运行库压缩包哈希，独立生成嵌入 Tcl、检查 x64 PE 与非系统依赖、附带许可，完成全部步骤后才发布。macOS 改用空暂存目录组装、验证后更新应用和架构对应 ZIP。
- 所需构建资料保留在源码目录；运行包包含各平台的二进制和依赖，不包含已删除的原回归源码。此次验证探针仅存在于临时工作目录，检查范围和数值对照见[当前交付检查](#validation)。
