# 无限长冷等离子体工作台

本项目是 **C11 + Tcl/Tk** 实现的天线和冷等离子体计算工作台。源码、构建文件和 CLI 位于 [`工程文件/c_workbench`](工程文件/c_workbench)。源码构建需要 C 编译器，图形版本还需 Tcl/Tk 开发库；命令行模式不依赖图形库。独立 `.app` 已自带运行库。

## 构建和启动

在项目根目录执行：

```sh
make                 # 构建 C11 工作台
make check           # 加载默认状态并检查参数
make run             # 打开 Tcl/Tk 窗口
```

也可以双击 `启动无限长冷等离子体工作台.command` 或 `无限长冷等离子体工作台.app`。Linux 或自定义 Tcl/Tk 安装可在 `工程文件/c_workbench` 中设置 `TCL_CFLAGS` 和 `TCL_LIBS`；缺少 GUI 开发文件时仍可构建 CLI。

根目录 Makefile 提供常用 CLI 包装：

```sh
make vacuum ARGS="--project 工程文件/examples/04_loop.rfproj --output /tmp/vacuum.csv"
make plasma ARGS="--project 工程文件/examples/等离子体螺旋示例.rfproj --output /tmp/plasma.csv"
make geometry ARGS="--project 工程文件/examples/05_helix.rfproj --obj /tmp/helix.obj"
```

直接调用工作台时，完整选项可用 `./工程文件/c_workbench/rf-workbench --help` 查看：

```sh
./工程文件/c_workbench/rf-workbench --check \
  --project 工程文件/examples/等离子体螺旋示例.rfproj
./工程文件/c_workbench/rf-workbench --vacuum \
  --project 工程文件/examples/04_loop.rfproj --output /tmp/vacuum.csv
./工程文件/c_workbench/rf-workbench --scan \
  --project 工程文件/examples/04_loop.rfproj --kpoints 41 --output /tmp/scan.csv
./工程文件/c_workbench/rf-workbench --plasma \
  --project 工程文件/examples/等离子体螺旋示例.rfproj --output /tmp/plasma.svg
./工程文件/c_workbench/rf-workbench --geometry \
  --project 工程文件/examples/05_helix.rfproj --obj /tmp/helix.obj
```

## 工作台布局

窗口采用「左侧参数输入—中间天线建模—右侧运算结果」三栏布局，可以缩放。左侧是「天线」「介质」「扫描」「射线追踪」四个参数页，字段附带单位，较长的参数页可以滚动。参数名称、单位、输入值、页签和说明统一使用 20 号字，分组标题使用 18 号粗体。参数名称与数值框紧邻，数值左对齐；右侧计算分类使用 20 号粗体、图示选项和操作按钮使用 18 号字，图例及坐标文字使用 14 号字。选项较多时可滚动查看，保留图表空间。无关的天线参数自动隐藏，常用项紧凑排列，高级相位、位置及采样参数默认收起。顶部左侧提供打开、保存、更多（另存为和内置示例），右侧为开始计算、停止和 CSV/SVG 导出；所有操作按钮统一为圆角风格并在同一行对齐，未保存的修改会在标题栏标记。

中间持续展示天线与圆柱容器的三维模型，随左侧参数更新。拖动可旋转、滚轮可缩放，点击「复位」恢复初始三维视角。输入无效或尚未完整时提示原因，并保留上一份有效模型。容器侧面以浅灰蓝色半透明填充；选中等离子体栏目时，内部区域以蓝色半透明圆柱显示。中间画布铺满中栏，圆柱只占总高度的 64%，上下各留 18% 空白并标注 +∞、−∞；标题、说明和操作按钮悬浮显示。横向不自动拉满；三维几何共用同一物理比例尺，半径参数直接决定显示宽度。默认视图每个画布高度对应 5 m，可用滚轮统一缩放。两者沿轴向显示到截断边界，保持均匀透明度，不做两端渐隐，也不绘制端盖。视图边缘不代表等离子体长度或轴向边界。两层表面与天线路径按深度混色，保留内部天线的可见性。

计算栏目依次为：**真空单模场 → 真空波数谱 → 等离子体单模场 → 等离子体波数谱 → 等离子体总场 → 电势波形 → 色散与射线**。“单模场”指固定 `(m,k_z)` 的 Fourier 分量；“总场”指设定范围内各 m、k_z 的相干叠加；“电势波形”保留单 m 的 k_z 带重建，具体图名仍为“电势虚部波形堆叠”。

真空和等离子体栏目同时显示，直接选择栏目即可计算对应模型，无需“启用等离子体”开关：真空模式共 8 种图示，包括场与能流、电流谱及波数扫描，真空天线电流谱只保留幅值图；等离子体模式共 30 种。“等离子体单模场”合并原来的场与电流、空间吸收与沉积栏目，提供电场幅值、磁场幅值、轴向能流密度、电流幅值、局部吸收、径向壳层沉积、波阻抗幅值共七张 r 曲线；吸收和沉积各保留一个入口，七图使用同一次固定 (m,k_z) 求解。局部吸收单位为 W/m，壳层沉积为 W，波阻抗幅值为 Ω。扫描范围和全模式 m 范围不参与单模式求解。“电势波形”栏目现显示一张“电势虚部波形堆叠”：先在外壁 Φ=0 的库仑规范中从全电磁场提取标量电势，再对单 m、扫描 k_z 带相干重建，画 Im Φ（V），沿 r 取波形、沿 z 堆叠；原三个电场分量堆叠已替换。该栏独立保存快照。给定源的“电流谱幅值”归入“真空波数谱”，独立的“天线电流谱”栏目已移除，材料与介电张量剖面不显示；已删除的累计吸收及累计比例谱图不恢复。

场图包括电场幅值、重建磁场幅值和轴向能流密度；电场、磁场及响应电流幅值图均显示矢量总幅值和三个分量，总幅值为各复分量模平方和的平方根。真空扫描提供电场幅值（截面最大值）、电流谱幅值、轴向能流谱、总电场谱热图和磁场谱热图。“等离子体波数谱”后的“等离子体总场”对可调 m 范围求和、对扫描 k_z 范围相干积分，提供与单模式栏目对应的七张 r-z 图，观察方位 φ 可调；电场、磁场和响应电流可切换总幅值及 r/φ/z 分量，轴向能流保留正负号。局部吸收为所选 φ 截面的 q，壳层沉积对完整圆周积分。波阻抗幅值先叠加总复电场和磁场，再计算 μ₀‖E_total‖/‖B_total‖（Ω），磁场节点留空；该局部幅值比不等于端口负载阻抗。求和范围、φ 和空间窗口/网格在“扫描”页设置。“全模式”表示所设有限范围，需检查截断收敛。等离子体扫描另含吸收谱、负载阻抗谱和吸收热图，不再显示 Er、Eφ、Ez 分量谱热图。

切换栏目会保留各自计算结果，模型预览随所选栏目显示真空或等离子体。七个计算栏目位于顶部工具栏下方，横向固定一排、等宽分格，使用 20 号粗体、清晰的深灰分割线和蓝底白字选中状态；栏目不随窗口换行或滚动。具体图示继续放在右侧，以浅蓝描边圆角标签显示，使用 18 号字，可随右侧宽度换行；计算后保留预选图示。图形直接读取 C 内核的结果数组；图例支持隐藏分量，移动指针可查看数值。

电势波形自动将 z 采样加密至至少 401 点（总网格上限内），最多绘制 501 条真实切片。采用细线，增益不随线数降低；图上“起伏 ×0.5 / ×1 / ×2 / ×4”按钮可直接调整显示，不必重新求解。波形任务保留原模态电势求解，省去未使用的空间吸收高阶积分，专用 CSV 记录真实复电势及求解误差。

波数扫描逐点运行，底部显示进度，可点击「停止」或按 Escape 取消。停止或计算失败时保留上一份完整结果；修改参数后，结果会标记为旧快照。导出 CSV 保存复数分量（热图导出波数、半径和数值），SVG 保存当前曲线或热图，中间建模区支持 OBJ 中心线导出。扫描失败点会在曲线和热图中留空，原因保存在 CSV 的 error 列。热图每个波数最多保留 129 个径向节点，峰值、能流和吸收积分仍使用完整计算网格。

快捷键：Command/Ctrl+O 打开，Command/Ctrl+S 保存，Command/Ctrl+Enter 开始计算。

## macOS 图形运行库与应用打包

项目内的 `工程文件/c_workbench/runtime` 提供本机架构的 Tcl/Tk 8.6.18，避免 macOS 26 下系统 Tk 8.5 的空白窗口问题。源码中的 Tcl 界面在构建时嵌入 C 可执行文件，运行时不需要读取源码。

```sh
make app             # 更新自带运行库和示例的独立 .app
make gui-test        # 检查参数读写、真实图表、扫描停止、快照和导出
make -C 工程文件/c_workbench runtime  # 从固定版本与校验和重建 macOS 运行库
```

`.app` 可整体移动，不依赖原仓库的位置。内置运行库当前为 arm64；其他架构的 Mac 可执行上述 runtime 构建后重新 `make app`。只需要命令行时，可用 `make -C 工程文件/c_workbench GUI=no` 构建不链接图形库的版本。

## 计算范围

天线目录统一为 17 类，PDF、程序菜单和项目 `type` 使用连续编号 1–17。单鞍为编号 6，双鞍形为编号 7，Nagoya III 为编号 8。双鞍形默认张角为 120°（2π/3 rad）；一般形状有四条轴向腿和两副反相闭合回路。几何示例采用 PDF 的当前核查参数。项目格式为 v8；读取 v7 时自动转换这三种天线的编号，保留原来的物理位型。 新增 13 轴向多环、14 平面螺旋、15 分段多环、16 鸟笼电流、17 蛇形电流；均为给定电流模板，使用独立的 13–17 号示例工程。14、15、17 号允许开曲线及其连续性方程确定的源电荷。鸟笼电流分布由输入规定，蛇形沿线相位梯度也由输入给定；不求馈电或电路谐振。

工作台按根目录 PDF 的解法实现圆柱 Fourier 模态全矢量 Maxwell 求解。真空与冷等离子体共用相容矢量有限元，保留模态内部耦合、轴心正则性、切向 PEC、材料界面和真实源面；冷等离子体的 S/D/P 张量完整进入全局方程。磁场由有限元基的解析旋度恢复，材料吸收和源供功分别积分并核对。

原有 12 类闭合源与新增五类给定电流共用统一路径积分，保留多半径位置、有向线元和源相位；开曲线保留端点电荷。矩形阵列间距、真实带宽和源相位实际参与求解。支持有限碰撞、无碰撞非共振和正碰撞极限吸收延拓。共振层和 TG 短波均参与内部网格预加密；延拓未通过径向、求积或碰撞序列检查时明确返回失败。

该模型背景只依赖半径、轴向无界、天线电流给定。固定 (m,k_z) 的吸收为 dP/dkz（W m），总功率需要进一步作模式求和与波数积分。“等离子体单模场”使用该单个谱点，画径向谱量及波阻抗幅值。空间求解对当前 m 的复数场逆 Fourier 重建，得到空间 E（V/m）、q(r,z)（W/m³）、窗口吸收（W）和有限波数带内的 R/X（Ω）；还通过 ∇²Φ=−∇·E、Φ(R)=0 提取库仑标量电势（V），为波形堆叠提供其虚部。电势使用原始 FEM 网格上的弱式，不以 E_z/(ik_z) 换算，k_z=0 也能处理。它是当前全电磁模型的纵向电势，不等于已经复现原论文的准静电边界源解。这些相干重建要求固定有限碰撞；观察窗口不是端板。必须分别检查 k 步长、谱截断与离散周期重复，电抗的谱尾可能比吸收更慢收敛。公式、操作与验证见 [无限长空间吸收与阻抗](工程文件/docs/无限长空间吸收与阻抗.md)。端口电流自洽、温度/动理学和有限端盖不在当前模型内。实现、中文注释入口、公式对应与独立 Bessel/ODE/功率验证见 [Maxwell 求解器实现与验证](工程文件/docs/Maxwell求解器实现与验证.md)。

CLI 通过 `--output` 将单点或扫描结果导出为 CSV/SVG，几何通过 `--obj` 导出中心线；界面导出时选择保存位置。临时结果可放入 `results/`，与源码、测试及示例分开保存。

## 固定频率与谱指标的全分支传播

直接选择右侧的「色散与射线」，一次计算得到同一物理参数快照下的 8 张图：径向波数实部、径向波数虚部、分支传播状态、群速度、几何光学适用性、射线轴向投影、射线方位角、射线功率衰减。选择前五张图时导出径向根表，选择后三张图时导出沿程轨迹表。频率、角向模数 m、轴向波数 kz 使用左侧现有输入；径向网格数控制局部分支诊断。在独立的“射线追踪”参数页中设置发射半径、z、方位角、能量方向、容差、最大步长和路径上限。群速度图合并 r/φ/z 分量，可分别勾选分量和四个分支，使用实线/虚线/点线区分分量；极化纵向份额、根间距、极化残差、射线径向波数和色散残差保留在内部计算与 CSV 中，不单独绘图。

建议打开 `工程文件/examples/指定起点射线示例.rfproj`：现有抛物线密度、均匀轴向磁场，固定 13.56 MHz、m=1、kz=10 rad/m，从 r=0.15 m、z=0 出发。能量方向按群速度选择；轨迹采样独立于径向诊断网格。到材料界面、PEC 壁、WKB/转向失效、路径或步数上限时记录终止原因。路径上限不设轴向端板；相对功率 P/P0 不代表天线对各分支的耦合功率。状态图使用分类色带；射线投影以绝对 z 为横轴、r 为纵轴，箭头沿时间递增。完整公式、误差控制和适用范围见 [当前圆柱模型的射线追踪](工程文件/docs/Maxwell求解器实现与验证.md#固定模式射线追踪)。

```sh
make branches ARGS="--project 工程文件/examples/全分支螺旋波示例.rfproj --output /tmp/branches.csv --rays /tmp/rays.csv"
```

复根使用当前碰撞响应；参考射线只在弱损耗、非退化且满足短波近似的部分生成。轨迹按群速度而非波数符号行进，遇到界面、转向或适用性失效时终止，原因保存在 CSV；没有合格射线时仍保留全部局部根与诊断。当前不自动计算反射/模式转换系数和天线激发各分支的绝对功率。数学推导、数值判据、算法与验证详见 PDF 第五章；接口见开发说明。

`工程文件/c_workbench/src/` 包含项目状态、项目读写、几何、真空求解器、等离子体求解器、绘图导出和 Tcl/Tk 界面；对应头文件位于 `工程文件/c_workbench/include/`。构建目标是 C11，核心代码使用 C 标准库和系统 Tcl/Tk C API。

示例项目位于 `工程文件/examples/`，其中 `等离子体螺旋示例.rfproj` 用于有限碰撞，`无限长空间吸收示例.rfproj` 提供空间窗口与波数重建设置，`二维波场堆叠示例.rfproj` 可在“电势波形”中查看电势虚部的径向波形堆叠，`全模式场与电流示例.rfproj` 提供 m=-3…3、可调 φ 的全模式 r-z 重建设置，`零碰撞共振螺旋示例.rfproj` 已设为正碰撞极限吸收延拓。

## 清理和检查

`make pdf` 会重新运行十七类天线的独立源谱与场核查，生成双鞍形有限带宽图、新增五类给定电流的几何与谱图及核查表，再用 XeLaTeX 更新 PDF。生成图形只需要 Python 标准库；PDF 所需的 TeX 源码、图形和核查数据保存在 `天线电流谱文档/`。

```sh
make test            # 参数检查、独立 Bessel/ODE/功率/共振参考、C 核心及 CLI 回归
make clean           # 删除对象文件、可执行文件、测试程序和自动生成头文件
```

`make check` 只验证参数状态；`make test` 还执行解析源谱、线性代数、材料/吸收、失败处理与 CLI 回归；`make gui-test` 执行图形工作流集成检查。真空、等离子体、扫描及几何命令可分别按上面的示例执行。所有计算均由当前 C11 工作台完成。

`make clean` 保留独立 `.app`、Tcl/Tk 运行库、项目文件及计算结果。清理后可直接打开 `.app`；`make run` 和 `.command` 启动器会重新构建源码程序。仓库只保留当前实现、文档和示例，历史结果及界面改版快照不作为基准数据。
