# 天线模型与电流源

本说明对应 `c_workbench/src/geometry.c` 的参数化模板、源积分和 OBJ 导出。有限带宽推导见 [PDF](../../天线电流谱文档/Finite_width_antenna_current_spectra.pdf) 及其 [LaTeX 源码](../../天线电流谱文档/Finite_width_antenna_current_spectra.tex)；场方程、边界与验证见 [Maxwell 求解器实现与验证](Maxwell求解器实现与验证.md)。

## 坐标、电流与相位

z 沿圆柱轴，phi=atan2(y,x)；从 +z 看向原点，+phi 为逆时针。几何方向不自动等于装置的环向或极向。每段有端点 a→b、带符号的支路系数 A 和单元相位 phi_e。峰值相量采用 `exp(-i omega t)`：

```text
I_e(t) = sigma I0 A cos(phi0 + phi_e - omega t)
sigma = current_direction = ±1
phi0 = global_phase_deg × pi/180
phi_e = e × phase_step × pi/180    （阵列单元）
```

整体反向等价于整体相位加 180°，不改变几何绕向。`winding_direction` 改变螺旋的 `dphi/dz=chi 2pi turns/L`，chi=±1；它不单独决定波的左右旋极化。阵列的电流相位与单元空间位置分别进入源积分。

## 模板与项目编号

当前目录为 17 类，PDF、菜单和 `.rfproj` 的 `type` 统一使用 1–17。项目格式为 v8；读取 v7 时自动迁移旧 6、7、8 号，保留物理位型。以下方向均取正电流并忽略整体相位：

| type | 模板 | 规定路径与主要参数 |
|---|---|---|
| 1 | ICRH 单带 | 同一 r=b 圆柱上的矩形回路：低方位腿沿 +z、顶弧沿 +phi、另一腿沿 -z、底弧沿 -phi；使用 width、L |
| 2 | ICRH 多带阵列 | 多个单带回路，中心方位间隔 spacing/b，电流相位递增 phase_step |
| 3 | Helicon 梳状阵列 | 同样采用贴圆柱矩形单元，保留各单元间距与馈电相位 |
| 4 | 全匝单环 | r=b，沿 +phi 闭合，带宽沿 z 展开 |
| 5 | 双臂螺旋 | 一臂向上、另一臂向下回流，两端完整环；两个闭合支路各带 I/2，共享主腿相加为 I；使用 turns、winding_direction、L |
| 6 | 单鞍 | 一个圆柱矩形回路，方向与单带相反；使用 arc_angle_deg、L |
| 7 | 双鞍形 | 两个相隔 pi 的矩形闭合回路，反相驱动；一般有四条直腿，代表张角 120°（2π/3 rad），端部为局部弧 |
| 8 | Nagoya III | 两条相对轴向腿和两端完整环；每条端部半环带 I/2，相当于未扭转的双臂连接 |
| 9 | 线电流含回流 | 局部 x=b 直弦从 -y 到 +y，外半径 c_ret 上的右侧圆弧返回；直弦长度 2 sqrt(c_ret²-b²) |
| 10 | 部分匝环 | b 上圆弧沿 +phi，两条径向馈线接到 c_ret 上的反向回流圆弧；使用 arc_angle_deg |
| 11 | 半 Nagoya | b 上沿 +z，顶端径向向外，c_ret 上沿 -z，底端径向向内；使用 L |
| 12 | 四半匝／半匝阵列 | 部分匝回路按 2pi e/N 均布；使用 elements、phase_step、arc_angle_deg，空间间距不使用 spacing |

| 13 | 轴向多环 | N 个 r=b 的完整圆环沿 z 按 spacing 排列，各环电流相位相差 phase_step；理想环体只有 m=0 |
| 14 | 平面螺旋 | z=z0 的开 Archimedean 曲线，inner_radius 到 b，turns 匝，均匀给定电流；两端保留源电荷 |
| 15 | 分段多环 | elements 个等间距半径；内环分两段，外环各四段，gap_angle_deg 指定间隙；给定 cos(q phi) 或 exp(i q phi) 的逐段电流 |
| 16 | 鸟笼电流 | N 条轴向腿和两端环；腿电流谐波 q=source_mode，端环电流由节点守恒规定，端环额外均匀环流取零 |
| 17 | 蛇形电流 | r=b 圆柱展开面上的连续开蛇形，N 段横向弧与 N-1 段轴向连接，I(s)=I exp(i current_phase_gradient s) |

`b=antenna_radius`，`L=antenna_length`，`c_ret=return_radius`。所有模板都使用 `azimuth_deg` 和 `axial_offset` 作整体旋转与平移。多半径回流满足 `b<c_ret<R`，并位于真空区；外壁半径 R 不自动充当电流回路的一段。接近壁回流极限时仍需检查网格与间隙收敛。

全匝环应选择 type=4。部分匝需要保留独立回流圆弧和馈线，不能将开角取整周后当成只有一条圆环。对于 N=4、相位差 90° 的均布半匝阵列，理想源具有 `m≡1 (mod 4)` 的选择规则；这来自几何与馈电相位。

## 几何参数与有限带宽

`width` 是单带及矩形阵列两根轴向腿的圆周弧长间距 d，张角 alpha=d/b；鞍形模板改用 `arc_angle_deg`。`band_width` 是独立的物理电流带宽，默认 0.02 m。两者不能互换。矩形带的外边界不能绕满一周，带宽须小于腿间距和轴向长度。

有限带宽通过跨宽闭合等流线的 `du/band_width` 平均实现。矩形等流线尺寸为 `(d+2u,L+2u)`，保留展开面上的矩形直角；螺旋、圆弧、馈线和回流按各自带面计算。`band_samples` 是宽度求积设置，积分还按相位变化细分；不能用可视中心线代替实际带面源。

场求解与展示源谱共用 `geometry_integrate_source`，但展示的径向汇总 `K_eff` 不包含源半径分布，不能把它集中加载到名义半径。半 Nagoya 的汇总 Kz 可以为零，而内外两腿分别加载后仍产生非零 Ez。

天线电流为给定输入。同一天线参数在真空和等离子体中的规定源谱相同；响应场和等离子体电流由材料与全局方程决定。模型不反求端口电压或受等离子体加载影响的导体电流。

## 单带零带宽谱参考

以下是 type=1 的解析检查，不能代替一般有限带宽积分。正变换为 `integral dz integral dphi/(2pi) exp[-i(m phi+k z)]`，记

```text
alpha = d/b
Pphase = exp(i phi0 - i m theta - i k z0)
Is = sigma I0
sinc(x) = sin(x)/x，sinc(0)=1

Kz   = i Is L/(pi b) sin(m alpha/2) sinc(k L/2) Pphase
Kphi = -i Is alpha/pi sinc(m alpha/2) sin(k L/2) Pphase
Kr   = 0
Jhat(r) = delta(r-b) (Kphi e_phi + Kz e_z)
```

K 的单位为 A，满足 `(m/b)Kphi+k Kz=0`。m=0 或 k=0 可直接取值，无需除以它们；m=k=0 时该矩形回路的汇总谱为零。弱形式源项为

```text
i omega mu0 b [conj(v_phi(b)) Kphi + conj(v_z(b)) Kz]
```

b 来自圆柱测度，Fourier 的 `1/(2pi)` 已包含在 K 中。Jr=0 是源路径的性质，不表示耦合场 Er 必须为零。

## 示例、导出与检查

`../examples/` 保留 17 类几何示例及有限碰撞、正碰撞极限吸收的等离子体示例。十七类几何示例的文件序号与 type 相同；例如 `04_loop.rfproj` 对应 type=4。

界面和 CLI 的 OBJ 导出保存有向中心线，`# rf_current phase_rad amplitude group` 注释保留支路相位、幅度与单元编号；物理带宽保存在项目中。外部 STL/OBJ 导入不属于当前工作流。

`make test` 检查 17 类源的几何、相位、闭合网络的电流收支、开曲线的源电荷、源展宽、解析单环与单带谱，以及反向、相位、旋转和平移关系。`make check` 只检查参数；`--geometry --obj PATH` 用于导出几何。材料方程、源加载及独立场验证统一在 [求解器文档](Maxwell求解器实现与验证.md) 中维护。

`make antenna-test` 使用独立解析表达式核查 1596 组源谱，并运行十七类天线的 34 次真空／等离子体求解。PDF 图由同一次核查导出的 C 几何生成，带面、电流正负和四条直腿的箭头均对应当前内核。

## 新增给定电流的输入约定

14、15 号使用 `inner_radius < antenna_radius`；15 号径向环数为 1–8，间隙角为 0–90° 的开区间。`source_mode=q` 定义输入电流分布，`selected_m` 选择输出 Fourier 分量；两者独立。`current_pattern=0` 是 cos(q phi)，=1 是 exp(i q phi)。鸟笼要求 N>=3 且 1<=q<N；端环电流由 T_j-T_(j-1)=G_j 确定，而不是统一赋 I0。蛇形的 width 是每段横向弧长，spacing 是轴向节距；current_phase_gradient 的单位为 rad/m，默认 0。

13–15 号的 band_width 表示轴向均匀源展宽，16、17 号表示角向均匀源展宽（弧长单位 m）；分别产生 sinc(kz W/2) 和 sinc(m W/(2b))。它们是明确规定的源平均，不是对微带基板或金属横截面的求解。平面螺旋没有真实端面窗，蛇形没有介质基板和地板，鸟笼没有电容或谐振求解。

14、15、17 号不人为补上闭合回流；有向开路径的端点和沿线电流变化对应 rho_ext=div(J)/(i omega)。完整 curl-curl Maxwell 方程保留这个响应，不能使用 div(J)=0 的简化。geometry_current_balance 对开曲线非零是预期结果。新测试以 psi=r² exp[-i(m phi+kz z)] 做独立分部积分，核对端点和沿线电荷项。

`GeometrySegment.phase_advance` 保留段内线性电流相位，OBJ 另用 `# rf_phase_advance` 注释导出。固定半径的线性相位段用指数乘 sinc 精确积分，跨半径段按径向单元切分后求积。原有 v7 工程缺少新增字段时采用确定的默认值；v8 采用 6 单鞍、7 双鞍形、8 Nagoya III；原 v7 的 6/7/8 自动转换为 7/8/6。
