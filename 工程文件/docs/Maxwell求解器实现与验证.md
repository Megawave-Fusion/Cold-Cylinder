# Maxwell 求解器实现与验证

更新：2026-10-20。实现依据为 `天线电流谱文档/Finite_width_antenna_current_spectra.pdf`。

当前实现是圆柱 Fourier 模态的全矢量频域 Maxwell 边值求解。真空和冷等离子体共用 `c_workbench/src/maxwell.c`，材料以完整介电张量进入同一个方程。

## 适用模型与 Fourier 约定

背景、材料界面和 PEC 圆管只随 r 变化；轴向无界，无端盖。几何显示中的 `length` 是观察窗口，不是求解域的轴向导电边界。天线是给定电流的有限宽度、零厚度带面，包含回流和馈线。天线电流不由导体内部或端口电路反求。材料为有阻尼的冷电子和单离子流体，B0 沿 z；没有温度输运、Landau 阻尼或有限 Larmor 半径响应。

采用峰值相量 `exp(i m phi+i kz z-i omega t)`，正变换为 `∫dz ∫dphi/(2pi)`，逆变换为 `sum_m ∫dkz/(2pi)`。不同 `(m,kz)` 独立；每个模态内的电场分量保留耦合。

| 对象 | 谱单位 |
|---|---|
| 电场 E_hat | V |
| 射频磁场 B_hat | T m |
| 规定体源 J_ant_hat、材料响应电流 J_pl_hat | A/m |
| 单源面 K、展示用径向汇总 K_eff | A |
| q_spec=Re(J_pl_hat·E_hat*)/2 | W/m |
| dP_abs/dkz=∫r q_spec dr | W m |

`dP/dkz` 不等于已经对波数和全部模式积分的总功率。GUI 的“累计吸收”和单点 CSV 都保留 W m。总功率要在选定模式和波数范围内积分，并检查谱截断与步长收敛。空间重建及带内复阻抗已由 `spatial.c` 提供，见 [无限长空间吸收与阻抗](无限长空间吸收与阻抗.md)。极限吸收的检查按单个谱片进行，不表示已证明极限可与完整谱积分交换。

## 相容有限元与边界条件

每个普通径向单元的自由度为 `(D_j,P_j,Z_j,P_(j+1),Z_(j+1))`。`Er=D_j`，`r Ephi` 和 `Ez` 分片线性。它包含分片标量势的梯度，保持 curl-grad 关系。轴心首单元按照 `m=0`、`|m|=1`、`|m|>=2` 分别采用 PDF 的正则基；特别是 `|m|=1` 的横向轴上场可以非零，满足 `Er(0)=-i Ephi(0)/m`。

PEC 外壁只消去切向自由度 `Ephi(R)=Ez(R)=0`，保留法向场。材料界面对齐网格，切向 E 通过共享自由度连续，切向 B 和法向有效 D 的匹配由弱式实现并随网格收敛。可以用 `rf_maxwell_evaluate(..., side=-1/+1, ...)` 检查同一界面的双侧迹。B 由基函数的解析旋度恢复，不跨界面或源面对采样数组差分。有限阶离散的 B 切向迹仍有离散误差，不把其有限网格值宣称为精确连续。

内部网格同时包含均匀基础点、材料界面、源面及必要的自适应点。正碰撞简单共振附近按 `ell≈Im(S)/|S0'|` 加密。局部冷等离子体色散的两支都用于限制单元相位和衰减增量，避免只分辨共振层却漏掉 TG 短波。基础单元数增加时，共振层和波长预加密也同步细化。内部上限为 131072 节点；超过时返回明确错误。显示仍使用 `radial_cells+1` 个均匀样本，内部积分不依赖显示样本。峰值指标在内部各单元的双侧端点和内部点估计；极窄层的曲线和热图仍可能受显示采样限制，峰值估计也需要网格收敛。

默认使用 16 点 Gauss 求积，`|m|>12` 使用 32 点。可用 `rf_maxwell_solve_order` 独立改变求积阶数。所有矩阵项都含圆柱权重 `r dr`。矩阵原半带宽 4，选主元后上带宽最多扩至 8；没有稠密回退。对称对角平衡只是数值变量缩放，不修改介电张量和物理源。

后向误差由原始受约束系统计算：`max|Au-f| / max_i(|f_i|+sum_j|Aij uj|)`，超过 1e-8 返回失败。它不能代替场、网格或谱收敛。

## 有限宽度与 17 类规定电流源

`geometry_integrate_source` 对给定等流线做 `du/band_width` 平均，然后沿路径积分 `I exp[-i(m phi+kz z)] dl/(2pi)`。圆柱半径测度与体源中的 `1/r` 已相消。每个源点保留自己的半径，展示谱 `K_eff` 不能用作实际场的集中源。

矩形带的长度和张角同时随宽度位置变化；螺旋和 Nagoya 的两条闭合支路各承载 I/2，共享主腿相加为 I；部分匝、半 Nagoya 和直弦分别保留多半径回流及径向馈线。矩形阵列使用 `spacing/b` 的单元位置，半匝阵列沿完整圆周均布。带宽、整体相位、绕向和电流方向均进入真实源积分。单鞍不再与双鞍形共用同一个源。

常半径段用 sinc 精确积分线性相位；跨径向单元的馈线先在网格节点处分段再求积。宽度方向也按相位梯度细分，避免高波数混叠。源积分和场积分的加密可以分别检查。

新增 13–17 号为轴向多环、平面螺旋、分段多环、鸟笼电流、蛇形电流。开曲线和沿线相位变化允许 div(J) 非零，其源电荷由 rho_ext=div(J)/(i omega) 决定；它们不满足下文仅针对原有闭合源的梯度正交检查，新增测试改用包含端点及沿线电荷的分部积分。原有全矢量 curl-curl 求解无需假定 div(J)=0。径向网格额外对齐分段环的各个半径。独立目录测试现覆盖 1596 组源谱和 34 次真空/等离子体求解，图和公式见 PDF 第一章新增五类部分。

## 三种材料求解方式

`plasma.c` 从物种动量方程 `M_s (nu_s-i omega) v_s=q_s(E+v_s×B0)` 得到冷等离子体张量。相量采用 `exp(-i omega t)`，`Omega_s=q_s B0/M_s` 保留电荷符号，`wp_s²=n_s q_s²/(epsilon0 M_s)`：

```text
epsilon_r = [[S,-iD,0],[iD,S,0],[0,0,P]]
S = 1 - sum wp_s² (omega+i nu_s) / [omega ((omega+i nu_s)²-Omega_s²)]
D = sum wp_s² Omega_s / [omega ((omega+i nu_s)²-Omega_s²)]
P = 1 - sum wp_s² / [omega (omega+i nu_s)]
```

电子与一个准中性离子种类采用独立有效阻尼；密度可均匀、抛物线或高斯。`r>a` 为真空，`r=a` 的材料值取内侧。反转 B0 时 D 反号，S/P 不变；B0=0 时 S=P、D=0；零密度恢复真空。材料响应电流为 `J_pl_hat=-i omega epsilon0 (epsilon_r-I) E_hat`。

- `solve_mode=0` / `--plasma-method finite`：给定有限碰撞；允许非奇异的零碰撞参数，但发现无碰撞内部 S0 根时明确拒绝普通函数求解。
- `solve_mode=1` / `collisionless`：无碰撞、非共振 Maxwell 边值问题。旧枚举名保留项目文件兼容，不把它解释为共振连接。
- `solve_mode=2` / `limiting` / `--plasma-resonance`：对 PDF 所述内部简单混合共振采用正碰撞延拓。先检查 D0/P0 非退化、材料系数有限和正参考阻尼，再依次缩放参考碰撞。

延拓每级先比较基础径向网格加密（层内和短波预加密同步），再比较 16/32 点单元求积，然后比较相邻碰撞级的积分吸收和固定层外复 E、cB。容差分别为 0.3%、0.03%、0.3%；延拓连续两级通过才报告成功，最多 18 级。基础径向加密最多 2048 单元，内部节点上限另行控制。任何一项未通过都返回失败，不返回未收敛的末级作为“极限”。当前使用数值正碰撞族，不声称实现了完整复平面 Frobenius 基的任意阶全局匹配。

没有内部简单混合共振时，极限模式求非共振无碰撞解。退化根、轴心/界面重合根、回旋材料极点及无有限全局匹配极限的情形分别报告；不能把所有谱峰称为 S0 共振。有限正碰撞回旋响应若材料有限，仍可走正常矢量有限元。

## 功率和质量检查

材料吸收使用独立物种速度耗散的非负公式。源供功由 FEM 复源内积得到：`dP_src/dkz=-Im(sum conj(u_a) f_a)/(2 omega mu0)`。两者独立计算。无损时供功虚实相消的舍入误差按复功率自然尺度归一，有可分辨吸收时按有功尺度归一；源供功不被吸收值覆盖。

`rf_physics.h` 统一 c0、epsilon0、mu0 并保持 `c0² mu0 epsilon0=1`，避免不同常量来源导致固定能量偏差。累计吸收使用内部单元积分，绘图中不再用显示网格梯形积分或多乘 2pi。

## 对称相消模态的数值处理

某些闭合天线在所选 m、kz 下不激发该 Fourier 分量。例如默认双鞍形的 m=0、单环的 m=±1；源积分可能只剩浮点舍入残余。这不是天线类型不受支持。求解器只对严格为零的装配右端直接返回零场；非零右端即使很小也照常求解，再用原始系统检查后向误差。旧的“近零源直接跳过求解”分支会留下非零 b，却用 E=0 检查 A E=b，误报后向误差约为 1；现已修正，1e-8 门限保持不变。

`template_mode_regression` 覆盖 12 类天线、m=-1/0/1、真空和等离子体共 72 组，包含零激励的模式。GUI 与 CLI 另复现默认双鞍形 m=0 的原报错场景。相消模式得到接近零的场和吸收是正确结果，不能自动改 m 后把另一模式的结果冒充原设置。


## 固定模式射线追踪

本模块保持现有圆柱设置：背景只依赖 r，均匀轴向磁场，轴向无界，外壁 PEC，冷电子与单离子模型。静态、轴对称、轴向平移不变使 f、m、kz 都沿射线守恒；不改变几何与材料模型。

在“固定f,m,kz全分支”模块计算；“扫描”页新增“固定 f,m,kz 射线”设置，包括 r0、z0、phi0_deg、群速度向内/向外/双向、相对容差、最大步长、最大路径与最大步数。可打开 `工程文件/examples/指定起点射线示例.rfproj`：r0=0.15 m、z0=0、phi0=0，现有抛物线密度，f=13.56 MHz、m=1、kz=10 rad/m。每个通过筛选的根从同一位置发射；不再从每个可传播区间的中点自动播种。存在根与实际发射是两种结果，拒绝发射的原因单独记录。

以无碰撞参考色散 D0 为 Hamilton 函数，固定 m、kz：

\[
\dot r=-D_{k_r}/D_\omega,\quad \dot z=-D_{k_z}/D_\omega,\quad
\dot\phi=-D_m/D_\omega=v_{g,\phi}/r,\quad \dot k_r=D_r/D_\omega.
\]

频率导数保持物理波矢不变，包括材料频散和 k0=omega/c 的变化。径向导数保持 kr、m、kz 不变，包括 kphi=m/r 的几何变化；材料导数由现有均匀、抛物线、高斯密度剖面的解析导数给出。

实际积分以物理路径 s 为自变量，令 V=|vg|，推进六个变量 `(r,z,phi,kr,t,tau)`：

\[
\frac{d(r,z,\phi,k_r,t,\tau)}{ds}
=\left(\frac{v_{g,r}}V,\frac{v_{g,z}}V,\frac{v_{g,\phi}}{rV},
\frac{D_r}{D_\omega V},\frac1V,2\operatorname{Im}k_r^{\rm actual}\frac{v_{g,r}}V\right).
\]

其中实际复根使用当前输入碰撞率，轨迹使用匹配的无碰撞参考；仅接受弱损耗、根分离、极化有效、WKB≤0.1 的部分。`P/P0=exp(-tau)` 为不含聚焦的相对射线管功率，不是场强平方，也没有计算天线对各分支的耦合比例。

自适应采用 RK4 步长加倍比较：一个整步与两个半步之差除以 15，结合六个变量的量纲尺度估计误差。试探终点的 kr 独立演化，然后求解同一参考分支校正；校正量同时参与误差验收。匹配使用实际/参考根距离及极化重叠。无法通过误差或物理筛选时拒步、缩步；不在 RK 子步跨过材料界面。积分最大步长与输出点一致受限，径向诊断网格不控制轨迹精度。

界面将色散与射线合并为一个栏目，保留五张径向诊断图：径向波数实部、径向波数虚部、分支传播状态、群速度和几何光学适用性，以及三张实际射线图：绝对 z-r 投影、方位角、P/P0。群速度同图显示四支的 r/φ/z 分量，可按分量和分支勾选，颜色区分分支，实线/虚线/点线区分分量。极化纵向份额、根间距、极化残差、参考 kr 和校正前色散残差保留在内部计算与 CSV 中，不单独绘图。方位角和 P/P0 以路径 s 为横轴；箭头沿时间递增，悬停报告终止原因。GUI 按当前选择的图导出径向根表或沿程轨迹表；CLI 的 `--output` 导出完整径向根表，`--rays` 导出独立自适应轨迹表，包含起点、时间、路径、参考/实际波数、单位极化、WKB、相对功率、校正前残差、kr 校正量及终止原因。径向根表的旧 ray_* 字段保留为无轨迹值，不再用它混装自适应轨迹。

```sh
make branches ARGS="--project 工程文件/examples/指定起点射线示例.rfproj --ray-r 0.15 --ray-z 0 --ray-direction both --ray-tol 1e-6 --ray-step 0.01 --ray-length 3 --output /tmp/branches.csv --rays /tmp/rays.csv"
```

其他覆盖项为 `--ray-phi DEG`、`--ray-max-steps N`。统一项目使用可选的 `# ray.*` 字段保存这些设置；旧项目缺少该块时采用默认值。`r0` 必须严格位于一个径向材料区域内，不能等于界面或外壁。

到等离子体/真空界面、PEC 壁、WKB/近轴/转向失效、材料极点、强阻尼、根退化、路径或步数上限时终止并记录原因。路径上限不是轴向端板，没有新增轴向反射。当前没有求界面反射/透射系数或模式转换功率，不能把几何终点解释成已知反射解。未进入下一传播区间的射线不会在该区间重新发射。

验证包括：真空解析群速度、完整波矩阵行列式、独立 Brillouin 能量速度、均匀各向异性介质中的解析 Cartesian 直线、非均匀剖面中的原点平移/旋转与径向诊断网格独立性、双向被动衰减、方向选择、拒绝不合格起点、PEC 事件与项目保存。均匀算例将最大路径步长从 0.8 减到 0.4、0.2 m，并把相对容差从 1e-3 收紧到 1e-5、1e-7 后，位置与 r0 乘方位角误差的最大值约为 1.50e-7、1.26e-8、1.13e-9 m。这是该解析算例的数值验证，不是任意输入的物理精度保证。
